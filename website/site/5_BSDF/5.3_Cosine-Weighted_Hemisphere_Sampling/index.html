5.3 Cosine-Weighted Hemisphere Sampling

Cosine-weighted hemisphere sampling is an importance sampling technique that drastically reducse variance and noise, since the sampling PDF matches the cosine term in the rendering equation.

We use Malley's method to generate cosine-weighted samples. It involves uniformly sampling a point on a disk then projecting it up to the hemisphere to generate a direction:

Implementation

As stated from 2.6 Uniform Disk Sampling, we can uniformly sample a point on a disk, given two random uniform numbers \(\xi_1\) and \(\xi_2\), with

\[ r = \sqrt{\xi_{1}}, \quad \phi = 2\pi\xi_{2} \]

and

\[ x = r\cos{\phi}, \quad y = r\sin{\phi} \]

Using Malley's method, we project this point onto the hemisphere:

\[ z = \sqrt{1 - x^2 - y^2} \]
vec3 CosineSampleHemisphere(inout uvec3 rng, SurfaceInteraction si) {
    vec2 xy = UniformSampleUnitDisk(rng);
    float x = xy.x;
    float y = xy.y;

    // Malley's Method
    float z = sqrt(max(1.0 - x * x - y * y, 0.0));

    vec3 wo = vec3(x, y, z);

    // Transform to world space
    return normalize(si.localToWorld * wo);
}

The following is the PDF for cosine-weighted hemisphere sampling (derived below).

float CosineSampleHemispherePdf(float nDotWi) {
    return nDotWi / PI;
}

Derivation

Sampling The Disk

From 2.6 Uniform Disk Sampling we derived that the joint PDF for uniformly sampling the polar coordinates \((r, \theta)\) on a unit disk is

\[ \text{PDF}_{R, \Phi}(r, \phi) = \dfrac{r}{\pi} \]

(Note that we swapped \(\theta\) for \(\phi\); it doesn't affect anything as it is only a change of variables)

Projecting to the Hemisphere

Since changing variables requires the absolute value of the Jacobian determinant \(J_{R, \Theta}\),

\[ \text{PDF}_{\Theta, \Phi}(\theta, \phi) = \text{PDF}_{R, \Phi}(r, \phi) \cdot |J_{\Theta, \Phi}| = \dfrac{r}{\pi} \cdot |J_{\Theta, \Phi}| \\ \]

Since \(r = \sin{\theta}\),

\[ |J_{\Theta, \Phi}| = \begin{vmatrix} \frac{\partial{r}}{\partial{\theta}} & \frac{\partial{r}}{\partial{\phi}} \\ \frac{\partial{\phi}}{\partial{\theta}} & \frac{\partial{\phi}}{\partial{\phi}} \end{vmatrix} = \begin{vmatrix} \cos{\theta} & 0 \\ 0 & 1 \end{vmatrix} = \cos{\theta} \\ \implies \text{PDF}_{\Theta, \Phi}(\theta, \phi) = |J_{\Theta, \Phi}| \cdot \dfrac{r}{\pi} = \dfrac{\cos{\theta}{\sin{\theta}}}{\pi} \]

Converting to Solid Angle

Since the rendering equation works in terms of solid angle \(\omega\) rather than the spherical angles \((\theta, \phi)\), we need to find \(\text{PDF}_{\Omega}\) rather than \(\text{PDF}_{\Theta, \Phi}\).

Since probability mass must be equal under different parametrizations, we use the standard \(d{\omega} = \sin{\theta}d{\theta}d{\phi}\) to find

\[ \text{PDF}_{\Omega}d{\omega} = \text{PDF}_{\Theta, \Phi}(\theta, \phi)d{\theta}d{\phi} \\ \text{PDF}_{\Omega}\sin{\theta}d{\theta}d{\phi} = \dfrac{\cos{\theta}{\sin{\theta}}}{\pi}d{\theta}d{\phi} \implies \text{PDF}_{\Omega} = \dfrac{\cos{\theta}}{\pi} \]

Monte Carlo Implementation

The standard Monte Carlo estimator for the rendering equation is

\[ L_o(\text{p}, \omega_o) \approx L_e(\text{p}, \omega_o) + \dfrac{1}{N}\sum_{j=1}^N{\dfrac{f(\text{p}, \omega_o, \omega_j)L_i(\text{p}, \omega_j)|\text{n}\cdot\omega_j|}{\text{PDF}_{\Omega_j}(\omega_j)}} \]

If we evaluate this for a perfectly diffuse surface using \(1\) sample, using our Lambertian BSDF \(f_s = \dfrac{\rho}{\pi}\) (derived in 5.2 Lambert's Cosine Law) and our cosine-weighted hemisphere sampling PDF, we get

\[ \begin{align*} L_o(\text{p}, \omega_o) &\approx L_e(\text{p}, \omega_o) + {\dfrac{\left(\frac{\rho}{\pi}\right)L_i(\text{p}, \omega_j)|\text{n}\cdot\omega_j|}{\left(\frac{|\text{n}\cdot\omega_j|}{\pi}\right)}} \\ &\approx L_e(\text{p}, \omega_o) + \rho \cdot L_i(\text{p}, \omega_j) \end{align*} \]
