4.2 Construction

Because pure Python recursion and calculations are much slower than other languages like C-based languages, we will use numpy and numba acceleration to help speed up the BVH construction. Our BVH will be a binary tree for simplicity.

Preallocation

We define a BVH node containing data about its AABB, children, the number of triangles it contains (only if it is a leaf node), and the depth of the BVH tree at that node.

The max possible nodes a binary tree can have is \(N = 2n - 1\), where \(N\) represents the total number of nodes and \(n\) represents the number of leaves (proved by mathematical induction here). We can then preallocate all the required lists with length \(2n - 1\) to reduce memory overhead while building (which causes stutters).

max_nodes = 2 * scene.num_triangles - 1

aabb_mins = np.zeros((max_nodes, 3), dtype=np.float32)
aabb_maxs = np.zeros((max_nodes, 3), dtype=np.float32)
left_child_indices = np.full(max_nodes, -1, dtype=np.int32)
right_child_indices = np.full(max_nodes, -1, dtype=np.int32)
first_tri_indices = np.zeros(max_nodes, dtype=np.int32)
tri_counts = np.zeros(max_nodes, dtype=np.int32)
is_leafs = np.zeros(max_nodes, dtype=np.int32)
depths = np.zeros(max_nodes, dtype=np.int32)

Another array, tri_indices = np.arange(scene.num_triangles) holds the scene triangle indices which is reordered in place so that every leaves triangles contains a contiguous slice of the array. first_tri_indices and tri_counts then calculates the slice of triangles needed to be tested during BVH traversal.

After fully building the arrays, the lists are all truncated to the actual number of total nodes to optimize on memory allocation:

aabb_mins = aabb_mins[:nodes_used]
aabb_maxs = aabb_maxs[:nodes_used]
left_child_indices = left_child_indices[:nodes_used]
first_tri_indices = first_tri_indices[:nodes_used]
tri_counts = tri_counts[:nodes_used]
is_leafs = is_leafs[:nodes_used]
depths = depths[:nodes_used]

Root Node

The BVH is built with a top-down approach. Thus, we must first consider the root node's data before subdividing:

nodes_used = 0

aabb_mins[0] = np.min(scene.vertices, axis=0)
aabb_maxs[0] = np.max(scene.vertices, axis=0)
first_tri_indices[0] = 0
tri_counts[0] = scene.num_triangles
depths[0] = 0

nodes_used += 1

Subdividing

After building the root node, we start subdividing the AABBs recursively.

Base Case

If the number of triangles is already few, the node becomes a leaf.

if tri_counts[node_idx] <= max_leaf_size:
    is_leafs[node_idx] = 1
    return

SAH Binning

To find the best possible axis and position to split each AABB, we use the Surface Area Heuristic (SAH) for quality.

Since this step is expensive, it is JIT-compiled with Numba and parallelized across all three axes \((x, y, z)\).

To determine split is the best, we use the SAH formulation:

\[ C_{\text{SAH}} = N_{\text{left}}A_{\text{left}} + N_{\text{right}}A_{\text{right}} \]

where \(C_{\text{SAH}}\) is the "cost" of the split, \(N\) represents the number of triangles in its respective side, and \(A\) represents the surface area of the respective split AABB.

Instead of finding every possible split, we instead use binning to find much cheaper approximate splits. Binning is a technique where triangle centroids along an axis are bucketed into a fixed number of bins \(B\), and only the \(B-1\) boundaries between are evaluated as candidate split planes.

For each axis:

  1. Populate bins with triangles

  2. Sweep left to right and right to left simultaneously to populate the left and right triangle counts around the split planes

  3. For each of the planes, compute the SAH cost

At the end of the loop, we compute the per-axis best costs and find the best split for the recursive step.

Implementations

The following is a pseudocode implementation for finding the best split for the AABBs:

@njit(parallel=True)
def find_best_split(centroids, vertices, bins):
    costs_per_axis = np.zeros(3, dtype=np.float32)
    pos_per_axis = np.zeros(3, dtype=np.float32)

    # prange parallelizes across the x, y, and z axes to evaluate the SAH
    for axis in prange(3):
        bin_mins, bin_maxs = populate_bins(centroids, vertices, axis, bins)

        left_areas, left_counts = sweep_left(bin_bounds, bin_counts)
        right_areas, right_counts = sweep_right(bin_bounds, bin_counts)

        for i in range(bins - 1):
            plane_cost = (left_counts[i] * left_areas[i]) + (right_counts[i] * right_areas[i])

            if plane_cost < costs_per_axis[axis]:
                costs_per_axis[axis] = plane_cost
                pos_per_axis[axis] = calculate_split_pos(bounds_min, bin_width, i)

    return get_best_split(costs_per_axis, pos_per_axis)

The following below is a pseudocode implementation for the subdivision recursive step. Note: to clearly illustrate the subdivision steps, the pseudocode replaces the BVH nodes as objects rather than flat numpy lists.

def subdivide(node):
    if node.tri_count <= max_leaf_size:
        node.is_leaf = True
        return

    best_axis, best_pos, best_cost = find_best_split(centroids, vertices, bins)

    parent_cost = calculate_node_cost(node)

    # Terminate if splitting costs more than keeping it as a leaf
    if (best_cost >= parent_cost):
        node.is_leaf = True
        return

    node.data = sort_triangles(node)

    # Stop if one of the sides are empty
    if node.left_count == 0 or node.right_count == 0:
        node.is_leaf = True
        return

    update_node_data(left_child)
    subdivide(left_child)

    update_node_data(right_child)
    subdivide(right_child)

Derivations

Binary Tree Max Nodes

The goal is to prove that a binary has a maximum of \(N = 2n - 1\) nodes, where \(N\) represents the total number of nodes and \(n\) represents the number of leaves. We can prove this by induction, rather than rederiving.

Base Case: (\(n\) = 1)

The total amount of nodes is \(N = 1\). Substituing \(n = 1\) into our formula \(N = 2n - 1\) results in \(N = 2(1) - 1 = 1\), and so the base case holds.

Inductive Hypothesis

Assume that for a full binary tree with \(k\) leaves there are \(2k - 1\) total nodes.

Inductive Step

We want to prove that a full binary tree with \(k+1\) leaves has \(2(k+1) - 1 = 2k + 1\) total nodes.

Let \(T\) be an arbitrary tree with \(n+1\) leaves. Since \(n \ge 1\), any \(2\) sibling leaves must have a parent node. Select any \(2\) sibling leaves and remove them. Call this new tree \(T'\), which is now a full binary tree with \((n+1)-2+1 = n\) leaves. By the inductive hypothesis, \(T'\) contains \(2n - 1\) leaves. Restoring the \(2\) removed leaves to \(T\) gives the total node count for \(T'\):

\[ (2n-1)+2 = 2n+1 = 2(n+1)-1 \]

Therefore, by mathematical induction, the formula holds for all \(n \ge 1\).
