9.5 Training

Dataset Creation

Each exported render used for training is loaded, converted to PyTorch tensors, then is processed to be used as the dataset for AI training.

Image Patching

Patching, or cropping a random section of the image is used to bound memory consumption and to effectively multiply the number of training renders available (as one image can yield multiple image patches).

The cropping below is only used for the training loop where sampling isn't needed to be deterministic. For parallelization, we can stack multiple random crops into one tensor.

for _ in range(patches_per_image):
    top = random.randint(0, h - patch_size)
    bottom = top + patch_size
    left = random.randint(0, w - patch_size)
    right = left + patch_size

    x_crop = x[:, top:bottom, left:right]
    target_crop = target[:, top:bottom, left:right]

    x_crop, target_crop = _augment(x_crop, target_crop)

    x_patches.append(x_crop)
    target_patches.append(target_crop)

x = torch.stack(x_patches)
target = torch.stack(target_patches)

The cropping below is only used for the validation loop. In the validation loop, the patches are then deterministically sampled.

for y in range(0, h - patch_size + 1, patch_size):
    for x_coord in range(0, w - patch_size + 1, patch_size):
        x_crop = x[:, y : y + patch_size, x_coord : x_coord + patch_size]
        t_crop = target[:, y : y + patch_size, x_coord : x_coord + patch_size]

        x_patches.append(x_crop)
        target_patches.append(t_crop)

# shape: (num patches, channels, batch_size, batch_size)
x = torch.stack(x_patches)
target = torch.stack(target_patches)

Augmentation

Image augmentation is used so the network sees various spatial arrangements every time, even if it is the exact same image.

Below, we only randomize rotation as other augmentation methods such as flipping may cause mismatches between the normal buffer and image data. Rotation can be reproduced in the real world by tilting the camera (roll), so a normal buffer stays correct under rotation without adjustment. However, flipping cannot be produced by a real moving camera. It corresponds to mirroring the 3D scene which negates all surface normals. Because the code doesn't apply the required correction, flipping the normal would leave the scene as if it isn't mirrored while the normal shows up as mirrored.

k = random.randint(0, 3)
if k > 0:
    x = torch.rot90(x, k, dims=[1, 2])
    target = torch.rot90(target, k, dims=[1, 2])

Train / Validation Split

The dataset is split 90/10 into train and validation sets. Because the training split and validation split need different __getitem__ behaviors, we randomly generate the datasets manually.

full_dataset_train = DenoiseDataset(settings.file_paths.ai_training.renders, is_validation=False)
full_dataset_val = DenoiseDataset(settings.file_paths.ai_training.renders, is_validation=True)

# Split 10% of the dataset to be validation cases
val_size = max(1, int(0.1 * len(full_dataset_val)))

gen = torch.Generator().manual_seed(999)
indices = torch.randperm(len(full_dataset_train), generator=gen).tolist()

train_dataset = Subset(full_dataset_train, indices[val_size:])
val_dataset = Subset(full_dataset_val, indices[:val_size])

train_loader = DataLoader(
    train_dataset,
    batch_size=5,
    shuffle=True,
    # Parallelize data loading across worker processes
    num_workers=4,
    # Apply fast CPU -> GPU transfer
    pin_memory=True,
    # Keep workers alive between epochs
    persistent_workers=True
)
val_loader = DataLoader(val_dataset, batch_size=1, shuffle=False)

For consistency, the train batch size of 5 matches the mini-batch size of Bako et al.

Because validation data is static and repeated across epochs, we cache it upfront rather than reloading it every epoch:

val_x_cache = []
val_target_cache = []
for x_grid, target_grid in val_loader:
    val_x_cache.append(x_grid.squeeze(0))
    val_target_cache.append(target_grid.squeeze(0))

To make validation cheaper, we only sample NUM_VAL_SAMPLES_PER_IMAGE patches from the batch to keep validation loss comparable from one epoch to the next.

val_patch_indices_cache = []
patch_gen = torch.Generator().manual_seed(9999)
for x_grid in val_x_cache:
    num_patches = x_grid.size(0)
    k = min(NUM_VAL_SAMPLES_PER_IMAGE, num_patches)
    patch_indices = torch.randperm(num_patches, generator=patch_gen)[:k]
    val_patch_indices_cache.append(patch_indices)

Training

Pretraining and Fine-Tuning

Following Bako et al., training happens in two phases:

  1. Pretrain: the diffuse and specular U-Nets are trained independently of eachother, and the losses are then computed independently.

    ```python diffuse_loss = criterion(diffuse_prediction, target_diffuse_demodulated) specular_loss = criterion(specular_prediction, target_specular_compressed)

    loss = diffuse_loss + specular_loss ```

  2. Fine-tune: after pretraining is done, the loss is calculated from the combined diffuse and specular contributions. This allows the network correct for any mismatches introduced when treating diffuse and specular independently.

    ```python diffuse_final = denoiser.remodulate(diffuse_prediction, albedo) specular_final = denoiser.decompress(specular_prediction) prediction_linear = diffuse_final + specular_final

    loss = criterion(prediction_linear, target_linear) ```

Processing

Like the forward pass in the KPCN, we must preprocess the input data before passing it through the U-Net. This includes demodulating (diffuse only) and logarithmic compression (both diffuse and specular) for both the noisy and converged renders. The inverse depth normalization is already done during dataset creation.

Since the pretrain and fine-tune stages need different data, we prepare all of it during preprocessing:

def _preprocess(x, target):
    diffuse = x[:, :3]
    specular = x[:, 3:6]
    albedo = x[:, 6:9]
    normal = x[:, 9:12]
    depth = x[:, 12:13]

    target_diffuse  = target[:, :3]
    target_specular = target[:, 3:6]

    diffuse_demodulated = denoiser.demodulate(diffuse, albedo)
    specular_linear = specular

    diffuse_compressed = denoiser.compress(diffuse_demodulated)
    specular_compressed = denoiser.compress(specular_linear)

    x = torch.cat([diffuse_compressed, specular_compressed, albedo, normal, depth], dim=1)

    target_linear = target_diffuse + target_specular

    target_diffuse_demodulated = denoiser.demodulate(target_diffuse, albedo)
    target_specular_compressed = denoiser.compress(target_specular)

    return x, diffuse_demodulated, specular_compressed, target_linear, target_diffuse_demodulated, target_specular_compressed

Training Loop

Optimization uses Adam at lr=1e-5 with L1 loss, consistent with Bako et al.

for x, target in train_loader:
    x = x.to(pytorch_device)
    target = target.to(pytorch_device)

    x = x.flatten(0, 1)
    target = target.flatten(0, 1)

    (x, diffuse_linear, specular_linear, target_linear,
        target_diffuse_demod, target_specular_comp) = _preprocess(x, target)

    optim.zero_grad()

    loss = _compute_loss(
        denoiser, x, diffuse_linear, specular_linear,
        target_diffuse_demod, target_specular_comp, target_linear,
        is_pretrain
    )

    loss.backward()
    optim.step()

    epoch_loss += loss.item() * x.size(0)

Validation Loop

Validation is consists of similar code to the training loop:

for x_grid, target_grid, patch_indices in zip(val_x_cache, val_target_cache, val_patch_indices_cache):
    x = x_grid[patch_indices].to(settings.pytorch_device)
    target = target_grid[patch_indices].to(settings.pytorch_device)

    (x, diffuse_linear, specular_linear, target_linear,
        target_diffuse_demod, target_specular_comp) = _preprocess(x, target)

    loss = _compute_loss(
        denoiser, x, diffuse_linear, specular_linear,
        target_diffuse_demod, target_specular_comp, target_linear,
        is_pretrain
    )

    val_loss += loss.item() * x.size(0)

Checkpointing

For checkpointing, we save the data to a temporary path first, then atomically replace the checkpoint file only if it successfully writes. If there is interrupted mid-write, the imcomplete .tmp file is discarded rather than replacing a working checkpoint. This ensures the last successfully saved checkpoint is never corrupted.

def save_checkpoint(checkpoint, path):
    path = Path(path)
    tmp_path = path.with_suffix(path.suffix + ".tmp")

    try:
        with tmp_path.open("wb") as f:
            torch.save(checkpoint, f)
        tmp_path.replace(path)

    except:
        tmp_path.unlink(missing_ok=True)
        raise

Resuming

To resume the last saved checkpoint, we use the following:

try:
    checkpoint = torch.load(settings.file_paths.denoiser.latest_checkpoint, map_location=settings.pytorch_device)
    denoiser.load_state_dict(checkpoint["model_state_dict"])
    optim.load_state_dict(checkpoint["optimizer_state_dict"])
    starting_epoch = checkpoint["epoch"] + 1

    if "train_history" in checkpoint and "val_history" in checkpoint:
        train_history = checkpoint["train_history"]
        val_history = checkpoint["val_history"]

    else:
        train_history = []
        val_history = []

    best_val_loss = min(val_history) if val_history else torch.inf

except FileNotFoundError:
    starting_epoch = 0
    train_history = []
    val_history = []
    best_val_loss = torch.inf
