# Russian Roulette

Russian roulette is a strategy that addresses the problem of expensive rays which don't contribute much to the final render. It terminates the ray based on a calculated termination probability to prevent it from costing expensive calculations further. The Russian roulette estimator is defined as

$$
F_{RR} =
\begin{cases}
0 & \xi < q \\
\frac{F}{1-q} & \xi \ge q
\end{cases}
$$

where $F$ represents the un-weighted throughput and $q$ is the termination probability.

We can prove that it is unbiased by calculating its expected value $E$.

$$
E[F_{RR}] = q\cdot(0) + (1-q)\left( \dfrac{F}{1 - q} \right) = F
$$E

Because $E[F_{RR}] = F$, Russian roulette converges to the correct throughput $F$.

```glsl
if (i > 3) {
    // Termination probability
    float q = 1.0 - max(throughput.r, max(throughput.g, throughput.b));
    float Xi = Pcg3d(rng).x;

    if (Xi < q) {
        // Return radiance so far
        break;
    } else {
        throughput = throughput / (1.0 - q);
    }
}
```
