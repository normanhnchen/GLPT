# Luminance Clamping

`ClampLuminance` clamps a `vec3` color to a set max luminance value.
Luminance is computed with the standard SRGB weights $(0.2126, 0.7152, 0.0722)$.
The luminance is clamped to a small value to avoid division by zero and thus, NaN propagation.

``` GLSL
vec3 ClampLuminance(vec3 col, float maxLum) {
    float lum = dot(col, vec3(0.2126, 0.7152, 0.0722));
    if (lum > maxLum) {
        col *= maxLum / max(lum, 1e-4);
    }
    return col;
}
```
