# Ray-Triangle Intersection (Möller-Trumbore)

`RayTriangleIntersect` is the ray-triangle intersection implementation for regular bounce rays.

```glsl
bool RayTriangleIntersect(Ray ray, Triangle tri, int triId, float closestT, inout SurfaceInteraction si) {
    vec3 e1 = tri.v1.pos - tri.v0.pos;
    vec3 e2 = tri.v2.pos - tri.v0.pos;
    vec3 pvec = cross(ray.d, e2);
    float det = dot(e1, pvec);

    // If det is close to 0, ray is parallel to the triangle
    if (abs(det) < 1e-7) return false;

    float invDet = 1.0 / det;

    vec3 tvec = ray.o - tri.v0.pos;
    float u = dot(tvec, pvec) * invDet;
    if (u < 0.0 || u > 1.0) return false;

    vec3 qvec = cross(tvec, e1);
    float v = dot(ray.d, qvec) * invDet;
    if (v < 0.0 || u + v > 1.0) return false;
    
    float t  = dot(e2, qvec) * invDet;
    // Check if the hit distance is positive and closer than current closest triangle
    if (t < EPSILON || t >= closestT) return false;

    if (backfaceCulling == 1) {
        Material mat = materials[tri.matId];
        if (mat.doubleSided == 0 && det < 0.0 && mat.transmission == 0.0) return false;
    }

    si.bary = vec2(u, v);
    si.t = t;
    si.triId = triId;
    si.ng = normalize(cross(e1, e2));
    return true;
}
```

`ShadowRayTriangleIntersect` is the ray-triangle intersection implementation for shadow rays.

```glsl
bool ShadowRayTriangleIntersect(inout uvec3 rng, inout Ray ray, Triangle tri, int triId, float closestT, inout VisibilityInteraction vi) {
    vec3 e1 = tri.v1.pos - tri.v0.pos;
    vec3 e2 = tri.v2.pos - tri.v0.pos;
    vec3 pvec = cross(ray.d, e2);
    float det = dot(e1, pvec);

    // If det is close to 0, ray is parallel to the triangle
    if (abs(det) < 1e-7) return false;

    float invDet = 1.0 / det;

    vec3 tvec = ray.o - tri.v0.pos;
    float u = dot(tvec, pvec) * invDet;
    if (u < 0.0 || u > 1.0) return false;

    vec3 qvec = cross(tvec, e1);
    float v = dot(ray.d, qvec) * invDet;
    if (v < 0.0 || u + v > 1.0) return false;
    
    float t = dot(e2, qvec) * invDet;
    // Check if the hit distance is positive and closer than current closest triangle
    if (t < EPSILON || t >= closestT) return false;

    Material mat = materials[tri.matId];
    if (backfaceCulling == 1) {
        if (mat.doubleSided == 0 && det < 0.0 && mat.transmission == 0.0) return false;
    }

    float w = 1.0 - u - v;
    vec2 texCoords = w * tri.v0.uv + u * tri.v1.uv + v * tri.v2.uv;

    if (mat.alphaMode != 0) {
        if (mat.hasBaseColTex == 1) {
            vec4 baseCol = texture(baseColorTextures, vec3(vec2(u, v), mat.baseTexId));
            mat.alpha = baseCol.w;
        }

        vec3 p = GetRayPoint(ray, t);

        if (mat.alphaMode == 1) {
            // MASK
            if (mat.alpha < mat.alphaCutoff) return false;
        } else if (mat.alphaMode == 2) {
            // BLEND
            if (Pcg3d(rng).x > mat.alpha) return false;
        }
    }

    vi.t = t;
    return true;
}
```

## Derivation

### Setup

A ray is parametrized as

$$
P(t) = O + tD
$$

where $O$ is the ray's origin and $D$ is the ray's direction.

A triangle with vertices $V_0, V_1, V_2$ is parametrized as

$$
P(u, v) = (1-u-v)V_0 + uV_1 + vV_2
$$

where $(u, v)$ are barycentric coordinates.

A point lies inside the triangle if and only if  $u \ge 0, v \ge 0$ and $u + v \le 1$.

### Solving the Linear System

An intersection occurs when the ray and triangle parametrizations are equal:

$$
\begin{align*}
O + tD &= (1-u-v)V_0 + uV_1 + vV_2 \\
O + tD &= V_0 - uV_0 - vV_0 + uV_1 + vV_2 \\
O + tD &= V_0 + u(V_1 - V_0) + v(V_2 - V_0)
\end{align*}
$$

Now, we let $E_1 = V_1 - V_0$, $E_2 = V_2 - V_0$, and $T = O - V_0$. Substituing and rearranging,

$$
\begin{align*}
O + tD &= V_0 + uE_1 + vE_2 \\
O - V_0 &= -tD + uE_1 + vE_2 \\
T &= \begin{bmatrix} -D & E_1 & E_2 \end{bmatrix} \begin{bmatrix} t \\ u \\ v \end{bmatrix}
\end{align*}
$$

### Cramer's Rule

For a system $Ax = b$, Cramer's rule gives

$$
x_i = \dfrac{\det{A_i}}{\det{A}}
$$

Applying this to our system,

$$
\begin{bmatrix} t \\ u \\ v \end{bmatrix} = \dfrac{1}{\begin{vmatrix} -D & E_1 & E_2 \end{vmatrix}}
\begin{bmatrix}
\det(T, E_1, E_2) \\
\det(-D, T, E_2) \\
\det(-D, E_1, T)
\end{bmatrix}
$$

### Scalar Triple Product

For a $3 \times 3$ determinant $A$, the scalar triple product states that
$a \cdot (b \times c) = A$, where $a \cdot (b \times c)$ is unchanging under cyclic permutation
and swapping any two operands negates the triple product.

To apply this to our case, we first define $Q = T \times E_1$ and $P = D \times E_2$. Therefore,

$$
\begin{align*}
\begin{bmatrix} t \\ u \\ v \end{bmatrix}
&= \dfrac{1}{(-D \times E_1) \cdot E_2}
\begin{bmatrix}
(T \times E_1) \cdot E_2 \\
(-D \times T) \cdot E_2 \\
(-D \times E_1) \cdot T
\end{bmatrix} \\

&= \dfrac{1}{(D \times E_2) \cdot E_1}
\begin{bmatrix}
(T \times E_1) \cdot E_2 \\
(D \times E_2) \cdot T \\
(T \times E_1) \cdot D
\end{bmatrix} \\

&= \dfrac{1}{P \cdot E_1}
\begin{bmatrix}
Q \cdot E_2 \\
P \cdot T \\
Q \cdot D
\end{bmatrix}
\end{align*}
$$
