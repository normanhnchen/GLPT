# Schlick-GGX Approximation

In Unreal Engine 4's physically based shading model, the geometry term is based on the Schlick model. Epic Games chose this model to better fit the Smith GGX model. For analytical light sources, they chose to follow Disney's remapping of $k = \frac{(Roughness+1)^2}{8}$.

The `GeometrySchlickGgx` function is given by

$$
G_1(\omega_o) = \dfrac{n\cdot\omega_o}{(n\cdot\omega_o)(1-k)+k}
$$

```glsl
float GeometrySchlickGgx(float nDotWo, float k) {
    float numer = nDotWo;
    float denom = nDotWo * (1.0 - k) + k;

    return numer / denom;
}
```

The `GeometrySmith` function is given by

$$
G(\omega_i, \omega_o) = G_1(\omega_i)G_1(\omega_o)
$$

```glsl
float GeometrySmith(vec3 n, vec3 wo, vec3 wi, float k) {
    float nDotWo = max(dot(n, wo), 0.0);
    float nDotWi = max(dot(n, wi), 0.0);
    float ggx1 = GeometrySchlickGgx(nDotWo, k);
    float ggx2 = GeometrySchlickGgx(nDotWi, k);
	
    return ggx1 * ggx2;
}
```
