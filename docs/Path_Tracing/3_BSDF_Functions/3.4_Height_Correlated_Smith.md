# Height-Correlated Smith

In 2014, Heitz mathematically proved that the original Schlick-GGX Masking-Shadowing functions 
lost energy on rough surfaces when viewed at grazing angles
(e.g. the method described in [3.4 Schlick-GGX Approximation](../3_BSDF_Functions/3.3_Schlick_GGX_Approximation.md)). This is because they separated the geometry term for each direction and didn't account for the height of the microfacets shadowing each other.

Heitz defines the Smith-GGX Masking function (Eq. 43) as

$$
G_1(\omega_o, \omega_m) = \dfrac{\chi^+(\omega_o\cdot\omega_m)}{1+\Lambda(\omega_o)}
$$

where $\chi^+(a) = \begin{cases} 0 & a \le 0 \\ 1 & a > 0\end{cases}$,
$a = \dfrac{1}{\alpha\tan{\theta_o}}$, and
$\Lambda(\omega_o) = \dfrac{-1+\sqrt{1+\frac{1}{a^2}}}{2}$.

Since $\tan$ is expensive to calculate in the shader, we can manipulate $G_1$ to

$$
G_1(\omega_o, \omega_m) = \chi^+(\omega_o\cdot\omega_m)\dfrac{2\cos{\theta_o}}{\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}
$$

(This is derived in the [derivations](#derivations) section below)

To match to code, we can substitute
$\cos{\theta_o} = \text{n}\cdot\omega_o$ and
$\cos{\theta_i} = \text{n}\cdot\omega_i$ to get

$$
G_1(\omega_o, \omega_m) = \chi^+(\omega_o\cdot\omega_m)\dfrac{2(\text{n}\cdot\omega_o)}{(\text{n}\cdot\omega_o)+\sqrt{\alpha^2+(\text{n}\cdot\omega_o)^2(1-\alpha^2)}}
$$

```glsl
float SmithGgxMasking(vec3 wo, vec3 n, float alpha2) {
    float nDotWo = abs(dot(n, wo));
    float denomC = sqrt(alpha2 + (1.0 - alpha2) * nDotWo * nDotWo) + nDotWo;

    return 2.0 * nDotWo / denomC;
}
```

Heitz defines the Smith-GGX Masking-Shadowing function (Eq. 99) as

$$
G_2(\omega_o, \omega_i, \omega_m) = \dfrac{\chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)}{1+\Lambda(\omega_o)+\Lambda(\omega_i)}
$$

Since $\tan$ is expensive to calculate in the shader, we can manipulate $G_2$ to

$$
G_2(\omega_o, \omega_i, \omega_m) = \chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)\dfrac{2\cos{\theta_o}\cos{\theta_i}}{{\cos{\theta_i}\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}+\cos{\theta_o}\sqrt{\alpha^2+\cos^2{\theta_i}(1-\alpha^2)}}}
$$

(This is derived in the [derivations](#derivations) section below)

To match to code, we can substitute
$\cos{\theta_o} = \text{n}\cdot\omega_o$ and
$\cos{\theta_i} = \text{n}\cdot\omega_i$ to get

$$
G_2(\omega_o, \omega_i, \omega_m) = \chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)\dfrac{2(\text{n}\cdot\omega_o)(\text{n}\cdot\omega_i)}{{(\text{n}\cdot\omega_i)\sqrt{\alpha^2+(\text{n}\cdot\omega_o)^2(1-\alpha^2)}+(\text{n}\cdot\omega_o)\sqrt{\alpha^2+(\text{n}\cdot\omega_i)^2(1-\alpha^2)}}}
$$

```glsl
float SmithGgxMaskingShadowing(vec3 wi, vec3 wo, vec3 n, float alpha2) {
    float nDotWi = abs(dot(n, wi));
    float nDotWo = abs(dot(n, wo));

    float denomA = nDotWo * sqrt(alpha2 + (1.0 - alpha2) * nDotWi * nDotWi);
    float denomB = nDotWi * sqrt(alpha2 + (1.0 - alpha2) * nDotWo * nDotWo);

    return 2.0 * nDotWi * nDotWo / (denomA + denomB);
}
```

## Derivations

### Simplifying $\Lambda$

Since Heitz's original Smith-GGX Masking function includes expensive GPU $\tan$ calculations, we can algebraically manipulate it to include cheaper calculations. Heitz's original equation for the function is

$$
G_1(\omega_o, \omega_m) = \dfrac{\chi^+(\omega_o\cdot\omega_m)}{1+\Lambda(\omega_o)}
$$

where $\chi^+(a) = \begin{cases} 0 & a \le 0 \\ 1 & a > 0\end{cases}$,
$a = \dfrac{1}{\alpha\tan{\theta_o}}$, and
$\Lambda(\omega_o) = \dfrac{-1+\sqrt{1+\frac{1}{a^2}}}{2}$.

Substituting $a = \dfrac{1}{\alpha\tan{\theta_o}}$ into $\Lambda(\omega_o)$, we get

$$
\Lambda(\omega_o) = \dfrac{-1+\sqrt{1+\alpha^2\tan^2{\theta_o}}}{2}
$$

Next, we need to manipulate $\Lambda(\omega_o)$.
Since $\tan^2{\phi} = \dfrac{\sin^2{\phi}}{\cos^2{\phi}} = \dfrac{1-\cos^2{\phi}}{\cos^2{\phi}}$,

$$
1+\alpha^2\tan^2{\theta_o} =
\dfrac{\cos^2{\theta_o}}{\cos^2{\theta_o}} + \dfrac{\alpha^2(1-\cos^2{\theta_o})}{\cos^2{\theta_o}}
= \dfrac{\cos^2{\theta_o}+\alpha^2(1-\cos^2{\theta_o})}{\cos^2{\theta_o}}
$$

Taking the square root and rearranging,

$$
\sqrt{\dfrac{\cos^2{\theta_o}+\alpha^2(1-\cos^2{\theta_o})}{\cos^2{\theta_o}}}
= \dfrac{\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{\cos{\theta_o}}
$$

Since $\sqrt{1+\alpha^2\tan^2{\theta_o}} = \dfrac{\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{\cos{\theta_o}}$, substituting this into $\Lambda(\omega_o)$ gives

$$
\begin{align*}
\Lambda(\omega_o) &= \dfrac{-1 + \frac{\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{\cos{\theta_o}}}{2} \\
&= \dfrac{-\cos{\theta_o} + \sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}
\end{align*}
$$

### Simplifying $G_1$

We have derived that $\Lambda(\omega_o) = \dfrac{-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}$.

Since $G_1(\omega_o, \omega_m) = \dfrac{\chi^+(\omega_o\cdot\omega_m)}{1+\Lambda(\omega_o)}$,

$$
\begin{align*}
G_1(\omega_o, \omega_m) &= \dfrac{\chi^+(\omega_o\cdot\omega_m)}{1+\frac{-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}} \\
&= \chi^+(\omega_o\cdot\omega_m)\dfrac{1}{\frac{2\cos{\theta_o}-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}} \\
&= \chi^+(\omega_o\cdot\omega_m)\dfrac{2\cos{\theta_o}}{\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}
\end{align*}
$$

### Simplifying $G_2$

We have derived that $\Lambda(\omega_o) = \dfrac{-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}$.

Since $G_2(\omega_o, \omega_i, \omega_m) = \dfrac{\chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)}{1+\Lambda(\omega_o)+\Lambda(\omega_i)}$,

$$
\begin{align*}
G_2(\omega_o, \omega_i, \omega_m)
&= \chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)\dfrac{1}{1+\frac{-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}+\frac{-\cos{\theta_i}+\sqrt{\alpha^2+\cos^2{\theta_i}(1-\alpha^2)}}{2\cos{\theta_i}}} \\
&= \chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)\dfrac{1}{1+\frac{-\cos{\theta_o}+\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}}{2\cos{\theta_o}}+\frac{-\cos{\theta_i}+\sqrt{\alpha^2+\cos^2{\theta_i}(1-\alpha^2)}}{2\cos{\theta_i}}} \\
&= \chi^+(\omega_o\cdot\omega_m)\chi^+(\omega_i\cdot\omega_m)\dfrac{2\cos{\theta_o}\cos{\theta_i}}{{\cos{\theta_i}\sqrt{\alpha^2+\cos^2{\theta_o}(1-\alpha^2)}+\cos{\theta_o}\sqrt{\alpha^2+\cos^2{\theta_i}(1-\alpha^2)}}}
\end{align*}
$$
