# 4.4 BVH Depth Heatmap Color

`GetBvhDepthColor` converts a node depth relative to the maximum node depth into a heatmap color.

```glsl
vec3 GetBvhDepthColor(int currDepth, int maxDepth) {
    float t = clamp(float(currDepth) / float(maxDepth), 0.0, 1.0);

    vec3 col;
    col.r = smoothstep(0.5, 0.75, t);
    col.g = smoothstep(0.0, 0.25, t) - smoothstep(0.75, 1.0, t);
    col.b = 1.0 - smoothstep(0.25, 0.5, t);

    return col;
}
```

# HSB To RGB

Adapted from Iñigo Quilez's HSB to RGB function: https://www.shadertoy.com/view/MsS3Wc

`HsbToRgb` converts a Hue, Saturation, Brightness (HSB) color into Red, Green, Blue, (RGB) color.

```glsl
vec3 HsbToRgb(in vec3 hsb){
    vec3 rgb = clamp(abs(mod(hsb.x * 6.0 + vec3(0.0, 4.0, 2.0), 6.0) - 3.0) - 1.0, 0.0, 1.0);
    rgb = rgb * rgb * (3.0 - 2.0 * rgb);
    return hsb.z * mix(vec3(1.0), rgb, hsb.y);
}
```

# BVH Angle-Based Color

`GetBvhAngleColor` converts the current BVH node minimum and maximum bounds to a color based on its angular position around the scene origin.


```glsl
vec3 GetBvhAngleColor(vec3 aabbMin, vec3 aabbMax) {
    vec3 center = (aabbMin + aabbMax) * 0.5;
    
    float theta = atan(center.z, center.x);
    
    // Map from [-π, π] to [0, 1]
    float c = theta / (2.0 * PI) + 0.5;
    
    vec3 hsb = vec3(c, 1.0, 1.0);
    return HsbToRgb(hsb);
}
```
