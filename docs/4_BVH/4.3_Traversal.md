# BVH Traversal

The program uses LIFO stack-based traversals of the BVH to find the closest ray-triangle intersection.

## Traversing Through The BVH

Since GLSL has no support for recursion, the BVH is traversed with a LIFO stack as follows:

1.  Push the root node onto the stack
2.  While the stack isn't empty, pop the latest node off and test the ray against its AABB.
    -   If the node is a leaf, test the ray against every triangle the node contains
    -   Else if the node is internal, test both of the children's AABB and
        push it based on a near-child-first ordering method

## Near-Child-First Ordering

When both of the current node's children are hit, they are pushed in order of their AABB entry distance `tNear`.
The farther AABB is pushed onto the stack first then the nearer AABB.
Since the stack is LIFO, the nearer child is popped and processed first.

This method meaningfully reduces the number of nodes visited (and increases performance based on testing),
since if the ray already intersects the nearer AABB, the farther one can get skipped!
Otherwise, both AABBs would have to be tested to find the closer intersection.

## Implementations

The following is a pseudocode implementation for the BVH traversal algorithm:

```glsl
bool Intersect(Ray ray, inout SurfaceInteraction si) {
    bool didIntersect = false;
    float closestT = INF;

    int nodeStack[MAX_BVH_DEPTH];
    int stackIdx = 0;
    // Push root node index onto the stack
    nodeStack[stackIdx++] = 0;

    vec3 invRayD = 1.0 / ray.d;

    while (stackIdx > 0) {
        // Pop the latest node index off
        int currIdx = nodeStack[--stackIdx];
        BvhNode currNode = BvhNodes[currIdx];

        if (AabbTest(ray, invRayD, currNode, closestT).hit) {
            if (currNode.isLeaf == 1) {
                // Leaf intersection; test all the triangles in the leaf
                for (int i = 0; i < currNode.triCount; i++) {
                    Triangle tri = GetTriangle(node, i);
                    if (RayTriangleIntersect(ray, tri, triIndex, closestT, si)) {
                        didIntersect = true;
                    }
                }
            } else {
                int left = currNode.leftChildId;
                int right = currNode.rightChildId;

                if (stackIdx < MAX_BVH_DEPTH) {
                    // Push children onto the stack if there are children
                    if (left != -1 && right != -1) {
                        BvhNode leftNode = BvhNodes[left];
                        BvhNode rightNode = BvhNodes[right];

                        AabbHit lh = AabbTest(ray, invRayD, leftNode, closestT);
                        AabbHit rh = AabbTest(ray, invRayD, rightNode, closestT);

                        // Push farther child first so the nearer one pops first (LIFO)
                        if (lh.tNear < rh.tNear) {
                            if (rh.hit) nodeStack[stackIdx++] = right;
                            if (lh.hit) nodeStack[stackIdx++] = left;
                        } else {
                            if (lh.hit) nodeStack[stackIdx++] = left;
                            if (rh.hit) nodeStack[stackIdx++] = right;
                        }
                    } else if (left != -1) {
                        nodeStack[stackIdx++] = left;
                    } else if (right != -1) {
                        nodeStack[stackIdx++] = right;
                    }
                }
            }
        }
    }

    return didIntersect;
}
```
