# Construction

Because pure Python recursion and calculations are much slower than other languages like C-based languages,
we will use numpy and numba acceleration to help speed up the BVH construction.
Our BVH will be a binary tree for simplicity.

## Preallocation

We define a BVH node containing data about its AABB, children,
the number of triangles it contains (only if it is a leaf node), and the depth of the BVH tree at that node.

The max possible nodes a binary tree can have is $N = 2n - 1$, where $N$ represents the total number of nodes and $n$ represents the number of leaves (proved by mathematical induction [here](#binary-tree-max-nodes)).
We can then preallocate all the required lists with length $2n - 1$ to reduce memory overhead while building (which causes stutters).

```python
max_nodes = 2 * scene.num_triangles - 1

aabb_mins = np.zeros((max_nodes, 3), dtype=np.float32)
aabb_maxs = np.zeros((max_nodes, 3), dtype=np.float32)
left_child_indices = np.full(max_nodes, -1, dtype=np.int32)
right_child_indices = np.full(max_nodes, -1, dtype=np.int32)
first_tri_indices = np.zeros(max_nodes, dtype=np.int32)
tri_counts = np.zeros(max_nodes, dtype=np.int32)
is_leafs = np.zeros(max_nodes, dtype=np.int32)
depths = np.zeros(max_nodes, dtype=np.int32)
```

Another array, `tri_indices = np.arange(scene.num_triangles)` holds the scene triangle indices 
which is reordered in place so that every leaves triangles contains a contiguous slice of the array.
`first_tri_indices` and `tri_counts` then calculates the slice of triangles needed to be tested during BVH traversal.

After fully building the arrays, the lists are all truncated to the actual number of total nodes to optimize on memory allocation:

```python
aabb_mins = aabb_mins[:nodes_used]
aabb_maxs = aabb_maxs[:nodes_used]
left_child_indices = left_child_indices[:nodes_used]
first_tri_indices = first_tri_indices[:nodes_used]
tri_counts = tri_counts[:nodes_used]
is_leafs = is_leafs[:nodes_used]
depths = depths[:nodes_used]
```

## Root Node

The BVH is built with a top-down approach. Thus, we must first consider the root node's data before subdividing:

```python
nodes_used = 0

aabb_mins[0] = np.min(scene.vertices, axis=0)
aabb_maxs[0] = np.max(scene.vertices, axis=0)
first_tri_indices[0] = 0
tri_counts[0] = scene.num_triangles
depths[0] = 0

nodes_used += 1
```

## Subdividing

After building the root node, we start subdividing the AABBs recursively.

### Base Case

If the number of triangles is already few, the node becomes a leaf.

```python
if tri_counts[node_idx] <= max_leaf_size:
    is_leafs[node_idx] = 1
    return
```

### SAH Binning

To find the best possible axis and position to split each AABB, we use the Surface Area Heuristic (SAH) for quality.

Since this step is expensive, it is JIT-compiled with Numba and parallelized across all three axes $(x, y, z)$.

To determine split is the best, we use the SAH formulation:

$$
C_{\text{SAH}} = N_{\text{left}}A_{\text{left}} + N_{\text{right}}A_{\text{right}}
$$

where $C_{\text{SAH}}$ is the "cost" of the split, $N$ represents the number of triangles in its respective side, and $A$ represents the surface area of the respective split AABB.

Instead of finding *every* possible split, we instead use *binning* to find much cheaper approximate splits.
Binning is a technique where triangle centroids along an axis are bucketed into a fixed number of bins $B$,
and only the $B-1$ boundaries between are evaluated as candidate split planes.

For each axis:

1. Populate bins with triangles

2. Sweep left to right and right to left simultaneously to populate the left and right triangle counts around the split planes

3. For each of the planes, compute the SAH cost

At the end of the loop, we compute the per-axis best costs and find the best split for the recursive step.

```python
@njit(nogil=True, fastmath=True, parallel=True, cache=True)
def find_best_split(centroids, vertices, bins):
    costs_per_axis = np.zeros(3, dtype=np.float32)
    pos_per_axis = np.zeros(3, dtype=np.float32)

    # Determine best split position using SAH
    for axis in prange(3):
        c = centroids[:, axis]

        bounds_min = np.min(c)
        bounds_max = np.max(c)
        
        if bounds_min == bounds_max:
            continue

        scale = bins / (bounds_max - bounds_min)
        
        bin_ids = np.minimum(bins - 1, (c - bounds_min) * scale).astype(np.int32)
        # AABBs
        bin_mins = np.full((bins, 3), np.inf)
        bin_maxs = np.full((bins, 3), -np.inf)

        bin_tri_counts = np.bincount(bin_ids, minlength=bins)

        # Populate the bins
        for i in range(len(c)):
            bin_idx = int(min(bins - 1, (c[i] - bounds_min) * scale))

            v0 = vertices[i][0]
            v1 = vertices[i][1]
            v2 = vertices[i][2]

            # Update the AABB for this bin
            for j in range(3):
                tri_min = min(v0[j], v1[j], v2[j])
                tri_max = max(v0[j], v1[j], v2[j])

                if tri_min < bin_mins[bin_idx, j]:
                    bin_mins[bin_idx, j] = tri_min
                if tri_max > bin_maxs[bin_idx, j]:
                    bin_maxs[bin_idx, j] = tri_max
        
        left_area = np.zeros(bins - 1)
        right_area = np.zeros(bins - 1)

        left_count = np.zeros(bins - 1)
        right_count = np.zeros(bins - 1)

        # AABB boxes
        lb_mins = np.full(3,  np.inf)
        lb_maxs = np.full(3, -np.inf)
        rb_mins = np.full(3,  np.inf)
        rb_maxs = np.full(3, -np.inf)

        left_sum = 0
        right_sum = 0
        
        # Gather data for the bins - 1 planes
        for i in range(bins - 1):
            left_sum += bin_tri_counts[i]
            left_count[i] = left_sum
            for j in range(3):
                if bin_mins[i, j] < lb_mins[j]:
                    lb_mins[j] = bin_mins[i, j]
                if bin_maxs[i, j] > lb_maxs[j]:
                    lb_maxs[j] = bin_maxs[i, j]
            left_area[i] = get_aabb_area(lb_mins, lb_maxs)

            right_sum += bin_tri_counts[bins - 1 - i]
            right_count[bins - 2 - i] = right_sum
            rb_mins = np.minimum(rb_mins, bin_mins[bins - 2 - i])
            rb_maxs = np.maximum(rb_maxs, bin_maxs[bins - 2 - i])
            right_area[bins - 2 - i] = get_aabb_area(rb_mins, rb_maxs)
        
        best_pos = 0
        best_cost = np.inf

        # Calculate the SAH cost for the bins - 1 planes
        scale = (bounds_max - bounds_min) / bins
        for i in range(bins - 1):
            if left_count[i] == 0 or right_count[i] == 0:
                plane_cost = np.inf
            else:
                plane_cost = left_count[i] * left_area[i] + right_count[i] * right_area[i]
            if plane_cost < best_cost:
                best_pos = bounds_min + scale * (i + 1)
                best_cost = plane_cost
        
        costs_per_axis[axis] = best_cost
        pos_per_axis[axis] = best_pos
    
    best_axis = -1
    best_pos = 0
    best_cost = np.inf

    for axis in range(3):
        if costs_per_axis[axis] < best_cost:
            best_axis = axis
            best_pos = pos_per_axis[axis]
            best_cost = costs_per_axis[axis]
    
    return best_axis, best_pos, best_cost
```

### Full Implementation

```python
def subdivide(self, node_idx):
    if self.tri_counts[node_idx] <= settings.bvh.max_leaf_size:
        self.is_leafs[node_idx] = 1
        return
    
    indices = self.tri_indices[self.first_tri_indices[node_idx] : self.first_tri_indices[node_idx] + self.tri_counts[node_idx]]
    triangles = self.scene_triangles[indices]
    centroids = self.scene_centroids[indices]
    vertices = self.scene_vertices[triangles]
    
    best_axis, best_pos, best_cost = find_best_split(centroids, vertices, settings.bvh.sah_bins)

    parent_cost = self.calculate_node_cost(node_idx)

    # Less cost to not split; terminate
    if (best_cost >= parent_cost):
        self.is_leafs[node_idx] = 1
        return
            
    axis = best_axis
    split_pos = best_pos
    
    i = self.first_tri_indices[node_idx]
    j = i + self.tri_counts[node_idx] - 1
    while i <= j:
        tri_idx = self.tri_indices[i]
        if self.scene_centroids[tri_idx][axis] < split_pos:
            i += 1
        else:
            # Swap triangle indices
            self.tri_indices[[i, j]] = self.tri_indices[[j, i]]
            j -= 1
    
    # Stop if one of the sides are empty
    left_count = i - self.first_tri_indices[node_idx]
    if left_count == 0 or left_count == self.tri_counts[node_idx]:
        self.is_leafs[node_idx] = 1
        return

    left_child_idx = self.nodes_used

    self.first_tri_indices[left_child_idx] = self.first_tri_indices[node_idx]
    self.tri_counts[left_child_idx] = left_count
    self.depths[left_child_idx] = self.depths[node_idx] + 1
    self.update_node_bounds(left_child_idx)

    self.nodes_used += 1

    self.left_child_indices[node_idx] = left_child_idx

    self.subdivide(left_child_idx)

    right_child_idx = self.nodes_used

    self.first_tri_indices[right_child_idx] = i
    self.tri_counts[right_child_idx] = self.tri_counts[node_idx] - left_count
    self.depths[right_child_idx] = self.depths[node_idx] + 1
    self.update_node_bounds(right_child_idx)

    self.nodes_used += 1

    self.right_child_indices[node_idx] = right_child_idx

    self.subdivide(right_child_idx)
```

## Derivations

### Binary Tree Max Nodes

The goal is to prove that a binary has a maximum of $N = 2n - 1$ nodes,
where $N$ represents the total number of nodes and $n$ represents the number of leaves.
We can prove this by induction, rather than rederiving.

#### Base Case: ($n$ = 1)

The total amount of nodes is $N = 1$. Substituing $n = 1$ into our formula $N = 2n - 1$ 
results in $N = 2(1) - 1 = 1$, and so the base case holds.

#### Inductive Hypothesis

Assume that for a full binary tree with $k$ leaves there are $2k - 1$ total nodes.

#### Inductive Step

We want to prove that a full binary tree with $k+1$ leaves has $2(k+1) - 1 = 2k + 1$ total nodes.

Let $T$ be an arbitrary tree with $n+1$ leaves.
Since $n \ge 1$, any $2$ sibling leaves must have a parent node.
Select any $2$ sibling leaves and remove them.
Call this new tree $T'$, which is now a full binary tree with $(n+1)-2+1 = n$ leaves.
By the inductive hypothesis, $T'$ contains $2n - 1$ leaves. Restoring the $2$ removed leaves to $T$ gives the total node count for $T'$:

$$
(2n-1)+2 = 2n+1 = 2(n+1)-1
$$

Therefore, by mathematical induction, the formula holds for all $n \ge 1$.
