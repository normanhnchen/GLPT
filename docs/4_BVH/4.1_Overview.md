# BVH

A bounding volume hierarchy (BVH) is a tree of nested axis-aligned bounding boxes (AABBs) which allows the path tracer to avoid testing against every triangle in the scene.
The core idea is simple: if a ray misses a node's AABB,
the entire node including every other node and every single triangle inside of it can be skipped.
Without a BVH, finding the closets ray-triangle intersection for a single ray costs $O(n)$ ray-triangle intersection tests.
With a BVH, this reduces to $O(\log{n})$ which is significant faster considering the millions of rays fired per frame.
