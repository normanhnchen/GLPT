# 9.1 Overview

While path tracing produces physically correct, unbiased images, the stochastic nature of Monte Carlo integration produces high-frequency variance (noise) at low samples. Instead of brute forcing to converge the image by increasing the sample count by thousands more, we can use an AI denoiser.

The AI denosier is built in PyTorch, using a Kernel-Predicting Convolutional Network (KPCN) with a U-Net architecture. By training the network to learn the relationship between noisy and converged renders, it can effectively learn to clean up Monte Carlo noise within a fraction of the time.
