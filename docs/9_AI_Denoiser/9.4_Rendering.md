# 9.4 Rendering

The KPCN needs a vast set of training renders pairs (noisy, converged) with diversity to prevent overfitting on just a handful of scenes. All the training data is rendered with GLPT's path tracer, including custom support for outputting all the required buffers for the network.

## Auto Rendering

Because rendering converged scenes with upwards of 4096 samples is time-consuming, a more efficient strategy is to automatically render all of the data based on preplaced camera positions and scenes.

### Camera Capturing

To generate preplaced camera positions for every scene used for AI training, we track the required camera data and cache the data to a `json` file. The `json` file can then be easily loaded and sent to the engine to loop through the camera captures.

### Rendering

To perform the auto rendering, we must have the engine automatically loop through ever single camera capture and every single scene. We also add an outermost loop considering the amount of iterations rendered through the entire scene collection.

The following pseudocode describes the structure of the described loops:

```python
for _ in range(num_pass_throughs):
    initialize_window()
    initialize_ctx()
    intialize_helper_classes()

    while not window.should_close():
        if scenes.are_finished:
            break
        
        scenes.load_next_scene()
        scene.materials.scramble()
        scene.hdri.scramble()

        camera_captures.load_next()

        initialize_buffers()

        # Render loop
        while not window.should_close():
            path_tracer.render()

            if camera_capture.is_finished:
                camera_captures.load_next()
                scene.materials.scramble()
                scene.hdri.scramble()

                update_buffers()
            
            if scene.is_finished:
                break
```

### Auto Exporting

To export the required buffers for the AI denoiser, we take a snapshot of the noisy data mid-render, but only export it once the converged data is also ready. This guarantees noisy and converged renders are always exported as a matched pair in case the app is terminated mid way through.

```python
def auto_save_training_renders():
    if noisy is None and total_samples >= settings.ai_training.rendering.noisy_samples:
        noisy = {
            "diffuse": get_ndarray_diffuse(),
            "specular": get_ndarray_specular(),
            "albedo": get_ndarray_albedo(),
            "normal": get_ndarray_normal(),
            "depth": get_ndarray_depth(),
        }
    
    if noisy is not None and total_samples >= settings.path_tracing.max_samples:
        target_diffuse = get_ndarray_diffuse()
        target_specular = get_ndarray_specular()
    
    if noisy is not None:
        if target_diffuse is not None and target_specular is not None:
            export_training_noisy(noisy)
            export_training_target_diffuse(target_diffuse)
            export_training_target_specular(target_specular)

            noisy = None
            target_diffuse = None
            target_specular = None
```

## Scene Randomization

Rather than training on a varied set of professional scenes from movies like what Bako et al. did, each scene is handmade. Since the handmade scene library is significantly smaller than a full production dataset, we can compensate through scene randomization.

### HDRI Randomization

We can randomize the scene HDRI in two ways:

1. Randomize the chosen HDRI for a scene

    ```python
    hdri_files = [hdri for hdri in hdris_path.iterdir()]
    random.shuffle(hdri_files)
    ```

2. Randomize the rotation, exposure, and color of the HDRI texture.

    The equirectangular HDRI texture must be first converted to Cartesian coordinates before applying the rotation matrix (rotating directly in equirectangular UV space would distort the image and provide mathematically incorrect results).

    ```python
    random_rot = np.random.uniform(0, 2 * np.pi, 3)
    random_exposure_factor = np.random.uniform(0.1, 10)
    random_color_factor = np.random.uniform(0, 2, 3)

    u = (np.arange(img_width) + 0.5) / img_width
    v = (np.arange(img_height) + 0.5) / img_height

    theta, phi = uv_to_spherical(u, v)
    x, y, z = spherical_to_cartesian(theta, phi)

    rot_mat = rotation_matrix(*random_rot)
    # Transform the matrix since numpy is row-major, the matrix is column-major
    rotated = np.stack([x, y, z], axis=-1) @ rot_mat.T

    x = rotated[..., 0]
    y = rotated[..., 1]
    z = rotated[..., 2]

    theta, phi = cartesian_to_spherical(x, y, z)

    u, v = spherical_to_uv(theta, phi)
    x_map = (u * img_width)
    y_map = (v * img_height)

    rotated_img = cv2.remap(
        original_img,
        x_map, y_map,
        interpolation=cv2.INTER_LINEAR,
        borderMode=cv2.BORDER_WRAP,
    )

    img = rotated_img * random_exposure_factor * random_color_factor
    ```

### Per-Material Randomization

For a given material, we can scramble its properties: base color, alpha, roughness, metallic, emissive color, emissive strength, transmission, and index of refraction (IOR).

```python
base_color[:3] = np.random.uniform(0, 1, 3)
if np.random.rand() < 0.1:
    base_color[-1] = np.random.uniform(0.1, 0.9)
    alpha_mode = 2 # BLEND

roughness = np.random.uniform(0, 1)
metallic = np.random.uniform(0, 1)

if _original_has_emission:
    emissive_color = np.random.uniform(0, 1, 3)
    emissive_strength *= np.random.uniform(0.1, 10)

if np.random.rand() < 0.3:
    transmission = np.random.uniform(0, 1)
    ior = np.random.uniform(1, 2.4)
```

### Texture Randomization

In the path tracer, materials are fetched via a texture ID. Therefore, we can scramble the original texture IDs, including a chance to remove the texture entirely and base it off of the per-material randomization described in the previous section.

```python
for mat in materials:
    # Per-material randomization; given in the section above
    mat.scramble()

    # Base color texture randomization
    if num_base_color > 0:
        if np.random.rand() < 0.5:
            mat.base_color_tex_id = np.random.randint(0, num_base_color)
            mat.has_base_color_tex = 1
        else:
            mat.base_color_tex_id = -1
            mat.has_base_color_tex = 0

    # Roughness texture randomization
    if num_roughness > 0:
        if np.random.rand() < 0.5: 
            mat.roughness_tex_id = np.random.randint(0, num_roughness)
            mat.has_roughness_tex = 1
        else:
            mat.roughness_tex_id = -1
            mat.has_roughness_tex = 0

    # Metallic texture randomization
    if num_metallic > 0:
        if np.random.rand() < 0.5: 
            mat.metallic_tex_id = np.random.randint(0, num_metallic)
            mat.has_metallic_tex = 1
        else:
            mat.metallic_tex_id = -1
            mat.has_metallic_tex = 0

    # Normal map randomization
    if num_normal > 0:
        if np.random.rand() < 0.5:
            mat.normal_tex_id = np.random.randint(0, num_normal)
            mat.has_normal_tex = 1
        else:
            mat.normal_tex_id = -1
            mat.has_normal_tex = 0
```
