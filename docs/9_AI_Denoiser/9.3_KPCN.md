# 9.3 KPCN

The neural network model used for the AI denoiser is a Kernel-Predicting Convolutional Network (KPCN) with a U-Net architecture. Instead of directly denoising the image, the network predicts for every pixel, a set of weights describing how to blend its noisy neighborhood into a converged estimate. The implementation is a custom adaptation of the paper from Bako et al., including its diffuse / specular split: two independent U-Nets each predict their own kernel weights for their respective diffuse or specular input passes. This is done as diffuse and specular passes have very different noise characteristics (diffuse noise is generally low-frequency while specular noise is generally high-frequency), so denoising each separately produces cleaner results than denoising a combined pass.

## Input

Both the diffuse and specular U-Nets are passed with the following buffers: diffuse, specular, albedo, normal, depth. Respectively, they include the number of channels: 3, 3, 3, 3, 1. Thus, together, there are $3+3+3+3+1 = 13$ input channels.

## Output

After passing the input buffers through the network, the denoiser outputs the final denoised render combining the diffuse and specular predicted renders.

## Processing

### Demodulation

Demodulation is the process of stripping out the albedo from the combined pass so that the network learns how to solely denoise the lighting rather than fine textures or detail. We demodulate before passing the buffers through the network, then remodulate after for the final denoised render. Note that demodulation is only applied to the diffuse pass.

Note that in the functions below, `x` should represent any arbitrary combined pass.

```python
def demodulate(self, x, albedo):
    return x / albedo.clamp(min=1e-1)
```

```python
def remodulate(self, x, albedo):
    return x * albedo.clamp(min=1e-1)
```

### Logarithmic Compression

Compression of the combined pass is essential due to the nature of linear HDR images. Because HDR radiance is unbounded, extreme fireflies can dominate the loss, permanently ruining the network's weights. Therefore, we can logarithmically compress the render before passing it through the network to control the large variance of HDR values.

Note that in the functions below, `x` should represent either the diffuse pass or the specular pass.

```python
def compress(self, x):
    return torch.log1p(x.clamp(min=0))
```

```python
def decompress(self, x):
    return torch.expm1(x).clamp(min=0)
```

### Depth Normalization

The raw depth pass outputed by GLPT's path tracer is unnormalized, meaning it represents the raw ray distances to the scene geometry (in arbitrary scene units). Also, the path tracer outputs a -1 depth value for rays missing the scene.

Because large unbounded values can dominate gradients and destabilize training, we want to normalize the depth buffer; specifically, we want to use the inverse depth convention $\frac{1}{d}$, where $d$ represents the depth value. With inverse depth, nearby geometry are mapped to larger values and further away objects are mapped to smaller values.

Note that in the implementation we add an offset to the denominator to prevent infinities from propagating through the network.

```python
def normalize_depth(self, depth):
    # Ray misses are set to -1.0 in the path tracer
    misses = depth == -1.0

    # Inverse depth
    inv = 1 / (depth.clamp(min=1e-4) + 1e-4)
    inv[misses] = -1.0

    return inv
```

## Forward Pass

### Padding

Padding the tensors are not optional; padding is required to prevent mismatch errors when concatenating skip connections. We use a default multiple value of 16 because the U-Net downsamples by a factor of $2$ four times, and so $2^4 = 16$. We use reflection padding, which fills padded regions with mirrored real content rather than zeros.

```python
def _pad_to_multiple(self, x, multiple=16):
    _, _, h, w = x.shape

    pad_h = (multiple - (h % multiple)) % multiple
    pad_w = (multiple - (w % multiple)) % multiple

    if pad_h == 0 and pad_w == 0:
        return x

    pad = nn.ReflectionPad2d([
        0, # Left
        pad_w, # Right
        0, # Top
        pad_h, # Bottom
    ])
    
    return pad(x)
```

### U-Net

The U-Net architecture is briefly defined in the [previous section](9.2_The_U-Net.md).

Because we are doing kernel prediction with kernel size of $k$, we want the U-Net to output $k^2$ channels. Similarly to Bako et al., we will use a kernel size of $k=21$.

### Softmax

At the end of the forward pass, we apply `torch.softmax`. This normalizes the $k^2$ weights at each pixel to sum to 1 which implicitly enforces energy conservation.

```python
weights = torch.softmax(weights, dim=1)
```

### Applying Predicted Kernels

After predicting the kernels to denoise the image, we have to actually apply the kernels.

In the implementation below, we use a nested for loop rather than using `torch.nn.unfold` to prevent possible memory errors when applying kernels on a large image, especially on the CPU device. Also, padding before applying the kernels is required to allow applying the kernels to edge pixels where there isn't a complete $k^2$ neigborhood around them.

```python
def _apply_kernel(self, weights, combined):
    B, _, H, W = weights.shape
    K = self.kernel_size
    pad_size = K // 2

    # Pad for the kernel neighborhood around the edge pixels
    pad = nn.ReflectionPad2d([pad_size, pad_size, pad_size, pad_size])
    # (B, 3, H, W) -> # (B, 3, H+2*pad, W+2*pad)
    padded = pad(combined)

    output = torch.zeros([B, 3, K * K, H, W], device=AI_DEVICE, dtype=torch.float32)
    # (B, 3, H+2*pad, W+2*pad) -> (B, 3, K*K, H, W)
    idx = 0
    for i in range(K):
        for j in range(K):
            output[:, :, idx, :, :] = padded[:, :, i:i + H, j:j + W]
            idx += 1

    # Add batch dimension at index 1
    # (B, K*K, H, W) -> (B, 1, K*K, H, W)
    w = weights.unsqueeze(1)

    # Apply weights to the combined image RGB channels
    return (output * w).sum(dim=2) # (B, 3, H, W)
```

## Full Implemention

Below is the full PyTorch implementation of the KPCN class:

```python
class KPCN(nn.Module):
    def __init__(self, in_channels=13, kernel_size=21):
        """
        The default in_channels is 13: diffuse(3) + specular(3) + albedo(3) + normal(3) + depth(1).
        kernel_size=21 per Bako et al. U-Net output is kernel_size**2 channels: one predicted
        set of weights based on the neighborhood per pixel.
        """

        super().__init__()

        self.kernel_size = kernel_size
        self.diffuse_unet = UNet(in_channels, kernel_size**2)
        self.specular_unet = UNet(in_channels, kernel_size**2)
    
    def _pad_to_multiple(self, x, multiple=16):
        """
        Pads tensors on the right and bottom sides to a multiple to prevent
        size mismatches when concatenating skip connections. 4 convolution blocks of 2x downsampling need dimensions
        divisible by 2**4=16.
        """

        _, _, h, w = x.shape

        pad_h = (multiple - (h % multiple)) % multiple
        pad_w = (multiple - (w % multiple)) % multiple

        if pad_h == 0 and pad_w == 0:
            return x

        # Use ReflectionPad2d instead zero-padding to preserve more real data at edges
        pad = nn.ReflectionPad2d([
            0, # Left
            pad_w, # Right
            0, # Top
            pad_h, # Bottom
        ])
        
        return pad(x)
    
    def forward(self, x, diffuse, specular):
        # Original spatial dimensions
        _, _, h, w = x.shape

        x = self._pad_to_multiple(x)
        diffuse = self._pad_to_multiple(diffuse)
        specular = self._pad_to_multiple(specular)

        # (B, K*K, H, W)
        diffuse_weights = self.diffuse_unet(x)
        specular_weights = self.specular_unet(x)
        # Normalize
        diffuse_weights = torch.softmax(diffuse_weights, dim=1)
        specular_weights = torch.softmax(specular_weights, dim=1)

        diffuse = self._apply_kernel(diffuse_weights, diffuse)
        specular = self._apply_kernel(specular_weights, specular)

        return diffuse[:, :, :h, :w], specular[:, :, :h, :w]
    
    def _apply_kernel(self, weights, combined):
        B, _, H, W = weights.shape
        K = self.kernel_size
        pad_size = K // 2

        # Pad for the kernel neighborhood around the edge pixels
        pad = nn.ReflectionPad2d([pad_size, pad_size, pad_size, pad_size])
        # (B, 3, H, W) -> # (B, 3, H+2*pad, W+2*pad)
        padded = pad(combined)

        output = torch.zeros([B, 3, K * K, H, W], device=settings.pytorch_device, dtype=torch.float32)
        # (B, 3, H+2*pad, W+2*pad) -> (B, 3, K*K, H, W)
        idx = 0
        for i in range(K):
            for j in range(K):
                output[:, :, idx, :, :] = padded[:, :, i:i + H, j:j + W]
                idx += 1

        # Add batch dimension at index 1
        # (B, K*K, H, W) -> (B, 1, K*K, H, W)
        w = weights.unsqueeze(1)

        # Apply weights to the combined image RGB channels
        return (output * w).sum(dim=2) # (B, 3, H, W)

    def denoise(self, diffuse, specular, albedo, normal, depth, denoised):
        with torch.no_grad():
            self.eval()
            # Convert from OpenGL textures to torch tensors
            diffuse = self._tex_to_tensor(diffuse, keep_channels=3) # RGBA -> RGB
            specular = self._tex_to_tensor(specular, keep_channels=3) # RGBA -> RGB
            albedo = self._tex_to_tensor(albedo, keep_channels=3) # RGBA -> RGB
            normal = self._tex_to_tensor(normal, keep_channels=3) # RGBA -> RGB
            depth = self._tex_to_tensor(depth, keep_channels=1) # RGBA -> R

            # Normalize depth via the inverse depth method
            depth = self.normalize_depth(depth)

            diffuse_linear = self.demodulate(diffuse, albedo)
            specular_linear = specular

            diffuse_feature = self.compress(diffuse_linear)
            specular_feature = self.compress(specular_linear)

            # 13 channels
            x = torch.cat([diffuse_feature, specular_feature, albedo, normal, depth], dim=1)

            diffuse_filtered, specular_filtered = self(x, diffuse_linear, specular_linear)

            diffuse_final = self.remodulate(diffuse_filtered, albedo)

            combined = diffuse_final + specular_filtered

            self._tensor_to_tex(combined, denoised)
    
    def _tex_to_tensor(self, tex, keep_channels=None):
        # bytearray() to copy the original as it is not writable (PyTorch requirement)
        data = bytearray(tex.read())
        width, height = tex.size
        channels = tex.components
        
        # Create 1d array from the texture data
        t = torch.frombuffer(data, dtype=torch.float32)
        # Reshape to OpenGL convention (H, W, C)
        t = t.reshape(height, width, channels)
        # Reshape to 3d tensor PyTorch convention (C, H, W)
        t = t.permute(2, 0, 1).contiguous()
        
        if keep_channels is not None:
            t = t[:keep_channels]
        
        # Add batch dimension at index 0 (C, H, W) -> (1, C, H, W)
        t = t.unsqueeze(0)

        return t.to(settings.pytorch_device)
    
    def _tensor_to_tex(self, tensor, denoised_tex):
        # Reshape to OpenGL texture data (H, W, C)
        t = tensor.squeeze(0) # Remove batch dimension
        
        t = t.permute(1, 2, 0).contiguous()
        
        data = t.cpu().numpy().tobytes()
        denoised_tex.write(data)

    def compress(self, x):
        return torch.log1p(x.clamp(min=0))

    def decompress(self, x):
        return torch.expm1(x).clamp(min=0)

    def normalize_depth(self, depth):
        # Ray misses are set to -1.0 in the path tracer
        misses = depth == -1.0

        # Inverse depth
        inv = 1 / (depth.clamp(min=1e-4) + 1e-4)
        inv[misses] = -1.0

        return inv

    def demodulate(self, x, albedo):
        return x / albedo.clamp(min=1e-1)

    def remodulate(self, x, albedo):
        return x * albedo.clamp(min=1e-1)
```
