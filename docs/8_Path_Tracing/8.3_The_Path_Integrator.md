# 8.3 The Path Integrator

The path integrator combines all the theoretical components of the path tracer into a single loop. It follows our path tracing estimator (see the updated [estimator](8.2_Russian_Roulette.md)) by tracing rays through the scene, maintaining a continuous throughput multiplier, and accumulating radiance.

The following is a pseudocode implementation of the integrator:

```glsl
vec3 throughput = vec3(1.0);
vec3 radiance = vec3(0.0);
Ray ray = CameraRay()

float prevBsdfPdf = 0.0;

for (int i = 0; i <= maxBounces; i++) {
    bool didIntersect = Intersect(ray);
    Material mat = GetMaterial(ray);

    if (!didIntersect) {
        /* Ray exited the scene */

        float misWeight = PowerHeuristic(prevBsdfPdf, HdriPdf(ray));
        radiance += ClampLuminance(throughput * SampleHdri(ray) * misWeight, maxLuminance);
        break;
    }

    if (mat.hasEmission) {
        float misWeight = PowerHeuristic(prevBsdfPdf, AreaLightPdf(ray));
        radiance += ClampLuminance(throughput * GetEmission(ray) * misWeight, maxLuminance);
    }
    
    radiance += ClampLuminance(throughput * SampleNeeWithMis(ray), maxLuminance);

    BsdfSample bsdf = SampleBsdf(ray);

    vec3 transmittance = BeerLambert(ray);

    throughput *= transmittance;
    throughput *= bsdf.color;

    throughput = ClampLuminance(throughput, maxLuminance);

    ray.direction = bsdf.direction
    ray.origin = OffsetRayOrigin(ray);

    /* Russian Roulette */
    
    if (i > 3) {
        float q = 1.0 - max(throughput.r, max(throughput.g, throughput.b));
        float Xi = RandFloat();

        if (Xi < q) {
            break;
        } else {
            throughput = throughput / (1.0 - q);
        }
    }
}
```
