# Path Tracing

The core of GLPT's physically based renderer is the path tracing algorithm which attempts to solve the rendering equation by simulating how physical light bounces around the scene.
Specifically, path tracing is a type of *backwards ray tracing* where rays are fired from the camera into the scene.

## Path Tracing Estimator

Our original Rendering Equation for a single bounce is defined as

$$
L_o(\text{p}, \omega_o) = L_e(\text{p}, \omega_o) + \int_{\Omega}{f(\text{p}, \omega_o, \omega_i)L_i(\text{p}, \omega_i)|\text{n}\cdot\omega_i|d\omega_i}
$$

(see [1.3 Rendering Equation](../1_Introduction/1.3_Rendering_Equation.md))

However, the path tracing algorithm is multi-bounce. Additionally, to prevent the number of rays at every bounce from growing exponentially, our algorithm evaluates only one incoming direction per bounce. In other words, $N = 1$. We can then rewrite the equation as

$$
L_o(\text{p}_k, \omega_o) \approx L_e(\text{p}_k, \omega_o) + {\dfrac{f(\text{p}_k, \omega_o, \omega_k)L_i(\text{p}_k, \omega_k)|\text{n}_k\cdot\omega_k|}{\text{PDF}_{\Omega_k}(\omega_k)}}
$$

where the subscript $k$ represents the current number of bounces.

The incoming radiance $L_i(\text{p}_k, \omega_k)$ is the outgoing radiance $L_o(\text{p}_{k+1}, -\omega_k)$ (since the outgoing direction at $\text{p}_{k+1}$ points back toward $\text{p}_k$). For notational consistency at the first point, we let $\omega_0 = -\omega_o$. Rewriting the equation for the algorithm starting at $\text{p}_1$ results in the path tracing estimator for an infinite number of bounces $k$:

$$
\begin{align*}
L_o(\text{p}_1, \omega_o)
&\approx L_e(\text{p}_1, \omega_o) + \left(\dfrac{f(\text{p}_1, \omega_o, \omega_1)|\text{n}_1\cdot\omega_1|}{\text{PDF}_{\Omega_1}(\omega_1)}\right)L_i(\text{p}_1, \omega_1) \\
&\approx L_e(\text{p}_1, \omega_o) + \left(\dfrac{f(\text{p}_1, \omega_o, \omega_1)|\text{n}_1\cdot\omega_1|}{\text{PDF}_{\Omega_1}(\omega_1)}\right)\left(L_e(\text{p}_2, -\omega_1) + \left(\dfrac{f(\text{p}_2, -\omega_1, \omega_2)|\text{n}_2\cdot\omega_2|}{\text{PDF}_{\Omega_2}(\omega_2)}\right)L_i(\text{p}_2, \omega_2)\right) \\
&\approx L_e(\text{p}_1, \omega_o) + \left(\dfrac{f(\text{p}_1, \omega_o, \omega_1)|\text{n}_1\cdot\omega_1|}{\text{PDF}_{\Omega_1}(\omega_1)}\right)L_e(\text{p}_2, -\omega_1) + \left(\dfrac{f(\text{p}_1, \omega_o, \omega_1)|\text{n}_1\cdot\omega_1|}{\text{PDF}_{\Omega_1}(\omega_1)}\right)\left(\dfrac{f(\text{p}_2, -\omega_1, \omega_2)|\text{n}_2\cdot\omega_2|}{\text{PDF}_{\Omega_2}(\omega_2)}\right)L_i(\text{p}_2, \omega_2) + \cdots \\
&\approx \sum_{k=1}^\infty \left( \prod_{j=1}^{k-1} \dfrac{f(\text{p}_j, -\omega_{j-1}, \omega_j)|\text{n}_j\cdot\omega_j|}{\text{PDF}_{\Omega_j}(\omega_j)} \right) L_e(\text{p}_k, -\omega_{k-1})
\end{align*}
$$

## Throughput

*Throughput* ($T_k$) is defined as the fraction of radiance survived at a bounce.

$$
T_k = \prod_{j=1}^{k} \dfrac{f(\text{p}_j, -\omega_{j-1}, \omega_j)|\text{n}_j\cdot\omega_j|}{\text{PDF}_{\Omega_j}(\omega_j)}, \quad
T_0 = 1
$$

Therefore, we have the final path tracing estimator

$$
L_o(\text{p}_1, \omega_o)
\approx \sum_{k=1}^\infty {T_{k-1}L_e(\text{p}_k, -\omega_{k-1})}
$$
