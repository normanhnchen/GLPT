# Trowbridge-Reitz GGX Distribution Function

The Trowbridge-Reitz GGX normal distribution function approximates the alignment of a surface's microfacets to the halfway vector $\omega_h$.

$$
D(n, \omega_h, \alpha) = \dfrac{\alpha^2}{\pi((n\cdot{\omega_h})^2(\alpha^2-1)+1)^2}
$$

```glsl
float TrowbridgeReitzGgx(vec3 n, vec3 wh, float alpha) {
    float alpha2  = alpha * alpha;
    float nDotWh  = max(dot(n, wh), 0.0);
    float nDotWh2 = nDotWh * nDotWh;
	
    float numer = alpha2;
    float denom = nDotWh2 * (alpha2 - 1.0) + 1.0;
    denom       = PI * denom * denom;
	
    // Clamp to prevent denom from clamping to 0.0 when underflowing (when roughness ~ 0.0)
    return numer / max(denom, 1e-4);
}
```
