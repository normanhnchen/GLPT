# Shadow Rays

Next Event Estimation (NEE) estimates direct lighting by directly sampling a point on a light source at every bounce, rather than waiting for a BSDF sample to hit a light by chance. However, there may be something blocking the path between the surface and the light source. Therefore, we use a *shadow ray* to test for this occlusion.

```glsl
VisibilityInteraction ShadowRayTest(inout uvec3 rng, SurfaceInteraction si, float dist, vec3 wi) {
    Ray shadowRay;
    vec3 offsetDir = dot(si.ng, wi) < 0.0 ? -si.ng : si.ng;
    shadowRay.o = OffsetRayOrigin(si.p, offsetDir);
    shadowRay.d = wi;

    VisibilityInteraction vi = TestVisibility(rng, shadowRay, dist);

    return vi;
}
```
