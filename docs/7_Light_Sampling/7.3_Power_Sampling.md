# Power Sampling

Power sampling is the process of stochastically choosing a light in the scene proportional to its radiant power.
This way, lights which overall provide more contribution to the final render are chosen more often, reducing noise/variance.
Since we are creating a discrete probability distribution over the lights in the scene, and we need to sample it millions of times per frame, the alias method is used as it is the most efficient method for this case.

## The Alias Method

The alias method is an efficient method with $O(1)$ time
especially useful for generating samples based on a discrete distribution.
The method works by creating $n$ bins, where $n$ represents the number of outcomes in the distribution.
Each bin represents the average $\frac{1}{n}$ of the total probability, regardless of the outcome's own probability.
For outcomes with a probability below $\frac{1}{n}$, they leave empty space in their own bin.
For outcomes with a probability above $\frac{1}{n}$, they have more space than their own bin can hold. For the outcomes with a probability above $\frac{1}{n}$, the excess probability is used to fill in the empty space for the outcomes with a probability below $\frac{1}{n}$. Each bin ends up storing

- $q_i$: the probability of keeping the $i$-th bin's outcome
- $\text{alias}_i$: the index of the $i$-th bin's outcome which fills in the remainder of the space
    (which there might not be any)
- $p_i$: the PMF of the $i$-th bin's outcome

### Alias Table Construction

Building this on the CPU side, we split outcomes into separate lists of being "under" or "over" the average probability.
We repeatedly pop one from each list to find its $q$ value and its $\text{alias}$ value.
If the outcome is over $\frac{1}{n}$ of the total probability it goes back into the appropiate list.
Repeat this process until both lists are completely empty (it doesn't matter which $2$ "under" and "over" outcomes are paired; the total probability is still conserved to be equal to $1$).

```python
def _build_alias_table(self, weights):
    n = len(weights)
    weights = np.asarray(weights, dtype=np.float64)
    total = weights.sum()

    p = np.zeros(n, dtype=np.float64)
    q = np.zeros(n, dtype=np.float64)
    alias = np.full(n, -1, dtype=np.int32)

    p[:] = weights / total

    under = []
    over = []
    for i in range(n):
        p_hat = p[i] * n
        if (p_hat < 1):
            under.append((p_hat, i))
        else:
            over.append((p_hat, i))

    while under and over:
        un_p_hat, un_i = under.pop()
        ov_p_hat, ov_i = over.pop()

        q[un_i] = un_p_hat
        alias[un_i] = ov_i

        p_excess = un_p_hat + ov_p_hat - 1
        if (p_excess < 1):
            under.append((p_excess, ov_i))
        else:
            over.append((p_excess, ov_i))

    for _, i in over:
        q[i] = 1
        alias[i] = -1
    for _, i in under:
        q[i] = 1
        alias[i] = -1

    return p.astype(f4), q.astype(f4), alias
```

### Alias Table Sampling

To sample from the precomputed alias table, we first must get a uniformly generated random number $\xi$. Using $\xi$, we can reuse it to generate both a random integer $\text{offset}$ and a random float $\text{up}$.

We let $\text{offset} = \min(\text{int}(\xi\cdot n),n-1)$ be the index of the outcome we sample from,
where $n$ represents the number of outcomes.

And, we then let $\text{up} = \min(\xi\cdot n - \text{offset}, 1-\epsilon)$
represent the uniform random float in range $[0, 1)$,
where $\epsilon$ represents a smaller number above $0$ (e.g. $0.0001$).

Using $\text{offset}$ and $\text{up}$, we can stochastically choose a random outcome to sample,
then choose whether or not to sample from the outcome's own probability $q$ or $\text{alias}$.

The following is a pseudocode implementation of alias sampling:

```glsl
int i = min(int(Xi * numOutcomes), numOutcomes - 1);
float up = min(Xi * numOutcomes - i, ONE_MINUS_EPSILON);

Bin bin = outcomes[i];
int idx;
if (up < bin.q) {
    idx = i;
    pdf = bin.p;
} else {
    idx = bin.alias;
    pdf = finiteLights[idx].p;
}
```
