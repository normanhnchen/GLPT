# Multiple Importance Sampling

To combine both strategies of BSDF sampling and direct light sampling (NEE), we must use something called multiple importance sampling (MIS). MIS uses weighting functions to solve the problem of weighting BSDF and NEE sampling contributions to reduce variance. An example of a weighting function is the balance heuristic. However, the power heuristic often reduces variance even more.

## Power Heuristic

The power heuristic is given by:

$$
\omega_s(x) = \dfrac{(n_f \text{PDF}_f(x))^2}{(n_f \text{PDF}_f(x))^2 + (n_g \text{PDF}_g(x))^2}
$$

where $s$ is the primary sampling strategy of the weight the heuristic is calculating for, 
$g$ is the other available strategies, and $n_i$ is the number of samples taken for strategy $i$.

```glsl
float PowerHeuristic(int nf, float fPdf, int ng, float gPdf) {
    float f = float(nf) * fPdf;
    float g = float(ng) * gPdf;
    return (f * f) / (f * f + g * g);
}
```
