# 7.6 Area Light Sampling

We define emissive triangles as area lights. To directly sample these area lights, we must randomly choose a triangle and uniformly sample a point on the triangle. A good method for choosing the light is power sampling explained in [7.4 Power Sampling](7.4_Power_Sampling.md). 

```glsl
vec3 Xi = Pcg3d(rng);

float triPdf;
Triangle tri = PowerEmissiveTriangleSample(Xi.x, triPdf);
```

## Uniform Sampling

To uniformly sample a point on a triangle, we first define $2$ uniform random variables $\xi_1$ and $\xi_2$ and consider a unit square with coordinates $(0, 0), (1, 0), (1, 1), (0, 1)$.
We will then map $\xi_1$ and $\xi_2$ to barycentric coordinates $(b_0, b_1, b_2) \in [0, 1]^3$.
A cheap mapping technique for this is to use linearly transform the square such that it is sheared into a right triangle.

We can split the unit square into two right triangles along the diagonal $y = x$.
If $\xi_1 < \xi_2$, then we are in the upper left triangle $(0, 0), (0, 1), (1, 1)$. Otherwise if $\xi_1 > \xi_2$, then we are in the bottom right triangle $(0, 0), (1, 0), (1, 1)$.

Applying a linear transformation to each half, we bring each corner $(1, 1)$ to $(0.5, 0.5)$,
creating a right triangle that occupies the bottom-left half of the unit square.

```glsl
if (Xi1 < Xi2) {
    b0 = Xi1 / 2.0;
    b1 = Xi2 - b0;
    b2 = 1.0 - b0 - b1;
} else {
    b1 = Xi2 / 2.0;
    b0 = Xi1 - b1;
    b2 = 1.0 - b0 - b1;
}
```

Because the transformation is purely linear, the area is scaled evenly which preserves the uniform distribution of the samples.

Since this method works with a right triangle within a unit square, because barycentric coordinate mapping is linear,
this method works with any triangle in 3d space.
