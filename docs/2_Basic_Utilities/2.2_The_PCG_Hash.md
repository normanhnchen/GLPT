# The PCG Hash

The `Pcg3d` function is used as a GPU hash randomizer via bit mixing. Returns a `float` `vec3` in range $[0, 1)^3$.

## Implementation

```glsl
vec3 Pcg3d(inout uvec3 rng) {
    rng = rng * 1664525u + 1013904223u;
    rng.x += rng.y*rng.z; rng.y += rng.z*rng.x; rng.z += rng.x*rng.y;
    rng ^= rng >> 16u;
    rng.x += rng.y*rng.z; rng.y += rng.z*rng.x; rng.z += rng.x*rng.y;
    // Convert to range [0, 1)
    return vec3(rng) / float(UINT32_MAX);
}
```

# RNG State Initialization

The `InitRngState` function returns a random `uvec3` RNG state based on the current pixel coordinates of the compute shader and the number of accumulated samples. This state is used as the RNG input for the `Pcg3d` function to provide GPU randomization.

## Implementation

```glsl
uvec3 InitRngState(ivec2 pixelCoords) {
    uvec3 state = uvec3(
        (pixelCoords.x) * 1512558u,
        uint(pixelCoords.y) * 1029858u,
        uint(totalSamples) * 739391335u
    );
    state ^= uvec3(1597334677u, 3812015801u, 2798796415u);
    return state;
}
```
