# Orthonormal Basis

`ONB` implements the method described by Duff et al. (2017) which fixes the floating point problem of the original method developed by Frisvad.

An orthonormal basis (ONB) is a a 3D local coordinate frame formed by 3 mutually perpendicular vectors (tangent, bitangent, normal) or $(dpdu, dpdv, \text{n})$. `ONB` builds the tangent and bitangent vectors from a given surface normal.

```glsl
void ONB(vec3 n, out vec3 dpdu, out vec3 dpdv) {
    float s = sign(n.z) == 0.0 ? 1.0 : sign(n.z);
    float a = -1.0 / (s + n.z);
    float b = n.x * n.y * a;
    dpdu = vec3(1.0 + s * n.x * n.x * a, s * b, -s * n.x);
    dpdv = vec3(b, s + n.y * n.y * a, -n.y);
}
```
