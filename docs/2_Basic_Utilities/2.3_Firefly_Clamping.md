# Firefly Clamping

In path tracing, "fireflies" are high-variance samples which are drastically brighter than neighboring pixels due to their low probability. Because their energy levels are astronomically higher than neighboring values, progressive accumulation takes a long time to average out those values.

To prevent fireflies, we can use firefly clamping to cap the maximum energy a sample can contribute. While this implements mathematical bias, it drastically reduces visual noise.

## Luminance Clamping

The first approach may seem to clamp each RGB color channel individually. However, this washes out colors. Luminance clamping solves this by calculating the luminance: overall brightness from the given color. Luminance is computed with the standard sRGB weights $(0.2126, 0.7152, 0.0722)$.

## Implementation

```glsl
float GetLuminance(vec3 col) {
    return dot(col, vec3(0.2126, 0.7152, 0.0722));
}
```

```glsl
vec3 ClampLuminance(vec3 col, float maxLum) {
    float lum = GetLuminance(col);
    if (lum > maxLum) {
        col *= maxLum / max(lum, EPSILON);
    }
    return col;
}
```
