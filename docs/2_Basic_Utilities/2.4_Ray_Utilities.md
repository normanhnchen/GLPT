# Ray Utilities

## Ray Point

`GetRayPoint` returns the `vec3` ray point given a ray distance $t$. The mathematical formula for a ray point is

$$
P(t) = O + tD
$$


``` GLSL
vec3 GetRayPoint(Ray ray, float t) {
    return ray.o + t * ray.d;
}
```

## OffsetRayOrigin

Adapted from Ray Tracing Gems, Chapter 6:
"A Fast and Robust Method for Avoiding Self-Intersection" (Wächter and Binder)

Floats lose precision the farther they are from the origin $(0, 0, 0)$.
To avoid self-intersection artifacts caused by this imprecision, the method from Wächter and Binder offsets the ray origin along the surface normal scaled by the actual distance from the origin.

### Implementation

```glsl
vec3 OffsetRayOrigin(vec3 p, vec3 n) {
    const float intScale = 256.0;
    const float floatScale = 1.0 / 65536.0;
    const float origin = 1.0 / 32.0;

    ivec3 of_i = ivec3(n * intScale);

    vec3 p_i = vec3(
        intBitsToFloat(floatBitsToInt(p.x) + ((p.x < 0.0) ? -of_i.x : of_i.x)),
        intBitsToFloat(floatBitsToInt(p.y) + ((p.y < 0.0) ? -of_i.y : of_i.y)),
        intBitsToFloat(floatBitsToInt(p.z) + ((p.z < 0.0) ? -of_i.z : of_i.z))
    );

    return vec3(
        abs(p.x) < origin ? p.x + floatScale * n.x : p_i.x,
        abs(p.y) < origin ? p.y + floatScale * n.y : p_i.y,
        abs(p.z) < origin ? p.z + floatScale * n.z : p_i.z
    );
}
```
