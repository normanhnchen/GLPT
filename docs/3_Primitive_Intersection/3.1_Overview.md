# Primitive Intersection

This chapter covers the fundamental ray-primitive intersection tests the path tracer is built on: 
[ray-AABB intersection](3.2_AABB_Testing.md) to accelerate rendering speed,
and [ray-triangle intersection](3.3_Ray-Triangle_Intersection.md) to evaluate scene geometry (because scenes are made of triangles).
These two tests are the core geometric building blocks of the renderer, used extensively during BVH traversal for heavy optimization (see [4.1 BVH Overview](../4_BVH/4.1_Overview.md) for more information on BVHs).
