# 3.2 AABB Testing

`AabbTest` determines whether a ray intersects an axis-aligned bounding box (AABB), using the slab method.

Since division is slower than multiplication, we precompute the inverse of the ray's direction `invRayD` before passing it into the function.

## Implementation

```glsl
AabbHit AabbTest(Ray ray, vec3 invRayD, BvhNode node, float closestT) {
    vec3 t0 = (node.aabbMin - ray.o) * invRayD;
    vec3 t1 = (node.aabbMax - ray.o) * invRayD;
    
    vec3 tMin = min(t0, t1);
    vec3 tMax = max(t0, t1);

    float tNear = max(max(tMin.x, tMin.y), tMin.z);
    float tFar  = min(min(tMax.x, tMax.y), tMax.z);
    
    AabbHit h;
    h.hit = tNear <= tFar && tFar > 0.0 && tNear < closestT;
    h.tNear = tNear;

    return h;
}
```

## Derivation

### Setup

A ray is parametrized as

$$
P(t) = O + tD
$$

where $O$ is the ray's origin and $D$ is the ray's direction.

An AABB is defined by a minimum point $B_{min} = (x_{min}, y_{min}, z_{min})$, and a maximum point $B_{max} = (x_{max}, y_{max}, z_{max})$

### Ray-Slab Intersection

To find where the ray intersects each face of the box (slab), we solve for the distance $t$.

For the $x$-axis:

$$
O_x + t_{0x}D_x = x_{min} \implies
t_{0x} = \dfrac{x_{min} - O_x}{D_x}
$$

$$
O_x + t_{1x}D_x = x_{max} \implies
t_{1x} = \dfrac{x_{max} - O_x}{D_x}
$$

We can similarly solve $t$ for the $y$ and $z$ axes.

Note that $t_{0x}$ is not necessarily the entry distance and
$t_{1x}$ is not necessarily the exit distance. For instance, if $D_x < 0.0$, the ray intersects the $x_{max}$ slab before the $x_{min}$ slab. Thus, we take the componentwise min and max instead:

$$
t_{min} = \min(t_0, t_1), \quad t_{max} = \max(t_0, t_1)
$$

where $t_0 = \begin{bmatrix} t_{0x} \\ t_{0y} \\ t_{0z} \end{bmatrix}$ and
$t_1 = \begin{bmatrix} t_{1x} \\ t_{1y} \\ t_{1z} \end{bmatrix}$.

Since the ray enters the box only once it enters all slabs, $t_{near} = \max(t_{min})$. Conversely, $t_{far} = \min(t_{max})$.

We count the intersection only if all of the following are true:
- $t_{near} \le t_{far}$: the line containing the ray intersects the AABB
- $t_{far} \ge 0.0$: the intersection is in front of the ray origin
- $t_{near} < t_{closest}$: the intersection is closer than the nearest hit found so far
