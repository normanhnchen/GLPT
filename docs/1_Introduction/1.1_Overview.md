# Overview

GLPT is a GPU path tracer built in Python using ModernGL and GLFW. Briefly speaking, a path tracer is an engine which simulates how light behaves in real life. To optimize performance, GLPT features advanced techniques that accelerate convergence speed while maintaining physically-based realism. These include but are not limited to spatial structures, importance sampling, and AI denoising.

## Docs

The docs provided are implementation references providing information behind the underlying techniques and concepts used in the path tracer. These may include derivations, proofs, explanations, or simply architecture including mappings to code implementations.
