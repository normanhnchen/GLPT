# GGX VNDF Importance Sampling

Standard microfacet normal distribution sampling often generates backfacing normals, creating wasted rays, variance, and noise. In 2018, Heitz described the method of sampling the GGX based on the distribution of visible normals (VNDF). This method drastically reduces variance and noise especially on reflective surfaces.

The algorithm is summarized below:

1. Stretch the view vector based on the roughness to a hemisphere configuration
2. Create an orthonormal basis around the view vector where $T_1$ is the tangent plane orthogonal to Z = (0, 0, 1)
3. Sample a point on a unit disk using a polar parametrization
4. Calculate the microfacet normal $\omega_m$ by projecting the point on the sphere with direction $\omega_o$
5. Unstretch the normal back into the ellipsoid configuration and renormalize

Note that we convert to and from tangent space bceause GGX VNDF importance sampling is done entirely in tangent space:

```glsl
vec3 ImportanceSampleGgxVndf(SurfaceInteraction si, vec2 Xi, vec3 wo, float roughness) {
    // Convert wo to tangent space for GGX VNDF importance sampling
    vec3 woTangent = si.worldToLocal * wo;
    
    // Stretch the view into the hemisphere configuration
    vec3 Vh = normalize(vec3(
        woTangent.x * roughness,
        woTangent.y * roughness,
        woTangent.z
    ));

    // Orthonormal basis
    // T1 must be the tangent plane orthogonal to Z = (0, 0, 1)
    // so a typical ONB function doesn't necessarily work
    float lensq = Vh.x * Vh.x + Vh.y * Vh.y;
    vec3 t1 = (lensq > 0.0) ? vec3(-Vh.y, Vh.x, 0.0) * inversesqrt(lensq) : vec3(1.0, 0.0, 0.0);
    vec3 t2 = cross(Vh, t1);

    // Sample the projected area of the hemisphere
    float r = sqrt(Xi.x);
    float phi = 2.0 * PI * Xi.y;
    float p1 = r * cos(phi);
    float p2 = r * sin(phi);
    float s = 0.5 * (1.0 + Vh.z);
    p2 = (1.0 - s) * sqrt(1.0 - p1 * p1) + s * p2;

    // Reproject onto the hemisphere
    vec3 wm = p1 * t1 + p2 * t2 + sqrt(max(0.0, 1.0 - p1 * p1 - p2 * p2)) * Vh;

    // Unstretch the normal back into the ellipsoid configuration
    wm = normalize(vec3(
        roughness * wm.x,
        roughness * wm.y,
        max(0.0, wm.z)
    ));

    // Transform wm from tangent sapce back to world space
    return normalize(si.localToWorld * wm);
}
```

## GGX VNDF PDF

Heitz and d'Eon defines the statistical distribution of visible microfacet normals $\omega_m$ from viewing direction $\omega_o$ as

$$
D_{\omega_o}(\omega_m) = \dfrac{G_1(\omega_o, \omega_m)|\omega_o\cdot\omega_m|D(\omega_m)}{|\omega_o\cdot \text{n}_s|}
$$

where $G_1$ is the masking function and $D$ is the distribution function.

The core idea of GGX VNDF sampling is using the $D_{\omega_o}$ function as the sampling PDF. In other words,

$$
\text{PDF}_{\Omega_m}(\omega_m) = \dfrac{G_1(\omega_o, \omega_m)|\omega_o\cdot\omega_m|D(\omega_m)}{|\omega_o\cdot \text{n}_s|}
$$

Since we want to integrate over the solid angle of the incident ray $\omega_i$ rather than
the microfacet normal $\omega_m$, we need the Jacobian $J_{\Omega_i}$ to find
$\text{PDF}_{\Omega_i}(\omega_i) = \text{PDF}_{\Omega_m}(\omega_m)\cdot|J_{\Omega_i}|$.

The desired Jacobian we want is
$J_{\Omega_i} = \left| \frac{d\omega_m}{d\omega_i} \right| = \frac{1}{4(\omega_o\cdot\omega_m)}$,
proven by Pharr et Al (2016).

Thus,
$
\text{PDF}_{\Omega_i}(\omega_i) =
\dfrac{G_1(\omega_o, \omega_m)|\omega_o\cdot\omega_m|D(\omega_m)}{|\omega_o\cdot \text{n}_s|} \cdot \left|\dfrac{1}{4(\omega_o\cdot\omega_m)}\right| =
\dfrac{G_1(\omega_o, \omega_m)D(\omega_m)}{4|\omega_o\cdot \text{n}_s|}
$

```glsl
float GgxVndfPdf(vec3 n, vec3 wo, vec3 wi, float alpha) {
    float nDotWo = dot(n, wo);
    vec3 wh = normalize(wo + wi);
    float alpha2 = alpha * alpha;

    float nDotWh = dot(n, wh);

    float D = TrowbridgeReitzGgx(nDotWh, alpha);

    float G1;
    if (geometryMode == 0) {
        /* Height-correlated Smith method */

        G1 = SmithGgxMasking(abs(nDotWo), alpha2);
    } else {
        /* Schlick-GGX approximation method */
        
        float roughness = sqrt(alpha);
        float k = (roughness + 1.0) * (roughness + 1.0) / 8.0;
        G1 = GeometrySchlickGgx(max(dot(n, wo), EPSILON), k);
    }

    return (D * G1) / max((4.0 * abs(nDotWo)), EPSILON);
}

```

## Monte Carlo Implementation

We know that $\text{PDF}_{\Omega_i}(\omega_i) = \dfrac{G_1(\omega_o, \omega_m)D(\omega_m)}{4|\omega_o\cdot \text{n}_s|}$

The Monte Carlo estimator for the [rendering equation](../1_Introduction/1.3_The_Rendering_Equation.md) is defined as 

$$
L_o(\text{p}, \omega_o) \approx L_e(\text{p}, \omega_o) + \dfrac{1}{N}\sum_{j=1}^N{\dfrac{f(\text{p}, \omega_o, \omega_j)L_i(\text{p}, \omega_j)|\text{n}\cdot\omega_j|}{\text{PDF}_{\Omega_j}(\omega_j)}}
$$

Applying GGX VNDF importance sampling to the Monte Carlo estimator with one sample, we have

$$
\begin{align*}
L_o(\text{p}, \omega_o) &\approx L_e(\text{p}, \omega_o) + {\dfrac{f(\text{p}, \omega_o, \omega_j)L_i(\text{p}, \omega_j)|\text{n}\cdot\omega_j|}{\text{PDF}_{\Omega_j}(\omega_j)}} \\
&\approx L_e(\text{p}, \omega_o) + \left(\dfrac{\frac{D(\omega_m)F(\omega_i, \omega_m)G_2(\omega_o, \omega_i, \omega_m)}{4|\text{n}_s\cdot\omega_o||\text{n}_s\cdot\omega_i|}|\text{n}_s\cdot\omega_i|}{\frac{G_1(\omega_o, \omega_m)D(\omega_m)}{4|\text{n}_s\cdot\omega_o|}}\right) L_i(\text{p}, \omega_j) \\
&\approx L_e(\text{p}, \omega_o) + \left(\dfrac{F(\omega_i, \omega_m)G_2(\omega_o, \omega_i, \omega_m)}{G_1(\omega_o, \omega_m)}\right) L_i(\text{p}, \omega_j)
\end{align*}
$$
