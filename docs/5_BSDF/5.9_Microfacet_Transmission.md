# Microfacet Transmission

When light transmit through a surface, it refracts according to Snell's law using a refraction half-vector $\omega_h$. To model this, the bidirectional transmittance distribution function (BTDF) is used.

Walter et al. defines the BTDF term (Eq. 21) as

$$
f_s(\omega_o, \omega_i, \text{n}_s) = \dfrac{|\omega_o\cdot\omega_h||\omega_i\cdot\omega_h|}{|\omega_o\cdot\text{n}_s||\omega_i\cdot\text{n}_s|}\dfrac{\eta_t^2(1-F(\omega_i\cdot\omega_h))G_2(\omega_o, \omega_i, \omega_h)D(\omega_h)}{(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}
$$

where the refraction half-vector $\omega_h = -\dfrac{\eta_i\omega_o+\eta_t\omega_i}{\|\eta_i\omega_o+\eta_t\omega_i\|}$.

Note: When total internal reflection (TIR) occurs,
the ray reflects along the boundary like a perfect mirror with $F(\omega_i\cdot\omega_h) = 1$.
The $(1-F(\omega_i\cdot\omega_h))$ term in the BTDF term shrinks to $0$ and thus the BTDF contribution shrinks to $0$.

The following is the implementation for the BTDF lobe in the BSDF sampling function:

```glsl
if (Xi.z < lobeProbs.specular + lobeProbs.transmission) {
    /* Transmission lobe */

    bounceDepth.transmission++;

    float alpha = mat.roughness * mat.roughness;
    float alpha2 = alpha * alpha;

    vec3 wh = ImportanceSampleGgxVndf(si, Xi.xy, wo, alpha);

    vec3 wi = refract(ray.d, wh, si.eta_i / si.eta_t);

    /* Total internal reflection (TIR) */

    // GLSL refract function returns vec3(0.0) on TIR
    if (wi == vec3(0.0)) {
        wi = reflect(ray.d, wh);

        float nsDotWi = dot(ns, wi);

        vec3 F = vec3(1.0);

        float G1 = SmithGgxMasking(abs(nsDotWo), alpha2);
        float G2 = SmithGgxMaskingShadowing(abs(nsDotWi), abs(nsDotWo), alpha2);

        float nsDotWh = dot(ns, wh);

        vec3 specular = F * (G2 / max(G1, EPSILON));

        bsdfSample.f = specular / lobeProbs.transmission;
        bsdfSample.wi = wi;

        return bsdfSample;
    }

    float wiDotWh = dot(wi, wh);
    float nsDotWh = dot(ns, wh);
    float nsDotWi = dot(ns, wi);

    vec3 F = FresnelSchlick(abs(wiDotWh), F0);

    float G1 = SmithGgxMasking(abs(nsDotWo), alpha2);
    float G2 = SmithGgxMaskingShadowing(abs(nsDotWi), abs(nsDotWo), alpha2);

    vec3 transmission = (1.0 - F) * (G2 / max(G1, EPSILON));

    bsdfSample.f = transmission / lobeProbs.transmission;
    bsdfSample.wi = wi;

    return bsdfSample;
}
```

## BTDF PDF

From [3.6 GGX VNDF](./3.6_GGX_VNDF.md) we know that $\text{PDF}_{\Omega_h}(\omega_h) = \dfrac{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)}{|\omega_o\cdot \text{n}_s|}$.

Since the refraction half-vector is defined differently than the reflection half-vector,
we must diverge from [3.6 GGX VNDF](./3.6_GGX_VNDF.md) and use a different Jacobian $J_{\Omega_i}^{t}$.
Walter et al. (2007) defines this

$$
J_{\Omega_i}^{t} =
\left| \dfrac{d\omega_h}{d\omega_i} \right| =
\dfrac{\eta_t^2|\omega_i\cdot\omega_h|}{(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}
$$

Therefore, we can find

$$
\begin{align*}
\text{PDF}_{\Omega_i}(\omega_i) &= \text{PDF}_{\Omega_h}(\omega_h)\cdot |J_{\Omega_i}^{t}| \\
&= \dfrac{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)}{|\omega_o\cdot \text{n}_s|} \left|\dfrac{\eta_t^2|\omega_i\cdot\omega_h|}{(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}\right| \\
&= \dfrac{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)\eta_t^2|\omega_i\cdot\omega_h|}{|\omega_o\cdot \text{n}_s|(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}
\end{align*}
$$

Note that this PDF is only used when TIR doesn't occur. With TIR, the BRDF PDF must be used.

```glsl
float BtdfPdf(vec3 n, vec3 wo, vec3 wi, float alpha, float eta_i, float eta_t) {
    float alpha2 = alpha * alpha;

    vec3 wh = normalize(eta_i * wo + eta_t * wi);
    if (dot(n, wh) < 0.0) wh = -wh;

    float nDotWo = dot(n, wo);
    float nDotWh = dot(n, wh);
    float woDotWh = dot(wo, wh);
    float wiDotWh = dot(wi, wh);

    float D = TrowbridgeReitzGgx(max(nDotWh, 0.0), alpha);
    
    float G1;
    if (geometryMode == 0) {
        /* Height-correlated Smith method */

        G1 = SmithGgxMasking(abs(nDotWo), alpha2);
    } else {
        /* Schlick-GGX approximation method */

        float roughness = sqrt(alpha);
        float k = (roughness + 1.0) * (roughness + 1.0) / 8.0;
        G1 = GeometrySchlickGgx(max(nDotWo, EPSILON), k);
    }

    float denom = eta_i * woDotWh + eta_t * wiDotWh;
    float jacobian = abs((eta_t * eta_t * wiDotWh) / max(denom * denom, EPSILON));
    return D * G1 * abs(woDotWh) / max(nDotWo, EPSILON) * jacobian;
}
```

## Monte Carlo Implementation

We know that $\text{PDF}_{\Omega_i}(\omega_i) = \dfrac{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)\eta_t^2|\omega_i\cdot\omega_h|}{|\omega_o\cdot \text{n}_s|(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}$.

Applying this to the Monte Carlo rendering equation and simplifying, we get

$$
\begin{align*}
\text{BTDF} &= \dfrac{f_s(\omega_i, \omega_o)|\text{n}_s\cdot\omega_i|}{\text{PDF}_{\Omega_i}(\omega_i)} \\
&= \dfrac{\frac{|\omega_o\cdot\omega_h||\omega_i\cdot\omega_h|}{|\omega_o\cdot\text{n}_s||\omega_i\cdot\text{n}_s|}\frac{\eta_t^2(1-F(\omega_i\cdot\omega_h))G_2(\omega_o, \omega_i, \omega_h)D(\omega_h)}{(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}|\text{n}_s\cdot\omega_i|}{\frac{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)\eta_t^2|\omega_i\cdot\omega_h|}{|\omega_o\cdot \text{n}_s|(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}} \\
&= \dfrac{|\omega_o\cdot\omega_h||\omega_i\cdot\omega_h|}{|\omega_o\cdot\text{n}_s||\omega_i\cdot\text{n}_s|}\dfrac{\eta_t^2(1-F(\omega_i\cdot\omega_h))G_2(\omega_o, \omega_i, \omega_h)D(\omega_h)}{(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}\dfrac{|\omega_o\cdot \text{n}_s|(\eta_i(\omega_o\cdot\omega_h)+\eta_t(\omega_i\cdot\omega_h))^2}{G_1(\omega_o, \omega_h)|\omega_o\cdot\omega_h|D(\omega_h)\eta_t^2|\omega_i\cdot\omega_h|}|\text{n}_s\cdot\omega_i| \\
&= \dfrac{(1-F(\omega_i\cdot\omega_h))G_2(\omega_o, \omega_i, \omega_h)}{G_1(\omega_o, \omega_h)}
\end{align*}
$$
