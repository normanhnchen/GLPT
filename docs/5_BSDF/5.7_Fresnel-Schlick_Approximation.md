# 5.7 Fresnel-Schlick Approximation

The Fresnel effect describes that the amount of light reflected from a surface changes depends
on the viewing angle. Schlick in 1993 approximated the Fresnel reflection (equations) as

$$
F(\cos{\theta}) = F_0 + (1-F_0)(1-\cos{\theta})^5
$$

where $F_0$ is the reflectance of the surface viewed at normal incidence.

```glsl
vec3 FresnelSchlick(float cosTheta, vec3 F0) {
    return F0 + (1.0 - F0) * pow(1.0 - clamp(cosTheta, 0.0, 1.0), 5.0);
}
```
