# 5.10 Lobe Selection

To decide whether to sample the specular, transmission, and diffuse lobes,
we must stochastically select them with a probability calculated from the material properties.
We cannot sample all the lobes at once as we only choose one outgoing ray direction for every bounce 
(or else there will be significant performance complications).

## Implementation

```glsl
LobeProbs ComputeLobeProbs(Material mat, float nsDotWo, vec3 F0) {
    vec3 F = FresnelSchlick(nsDotWo, F0);
    float weight = GetLuminance(F);

    float pSpec = clamp(weight, 0.05, 0.95);
    pSpec = mix(pSpec, 1.0, mat.metallic);
    float pTrans = (1.0 - pSpec) * mat.transmission;
    float pDiff = 1.0 - pSpec - pTrans;
    
    LobeProbs lobeProbs;
    lobeProbs.specular = pSpec;
    lobeProbs.transmission = pTrans;
    lobeProbs.diffuse = pDiff;

    return lobeProbs;
}
```

## Derivations

### Lobe Probabilities

We need to derive that `ComputeLobeProbs` computes stochastic probabilities which sum to $1$. 

We can translate `ComputeLobeProbs` into the math functions

$$
\begin{align*}
P_{\text{spec}}(\omega_o) &= (1-M_{\text{metallic}})\cdot\max(0.05, \min(F(\text{n}_s\cdot\omega_o) \cdot W_{\text{lum}}, 0.95)) + M_{\text{metallic}} \\
P_{\text{trans}}(\omega_o) &= (1 - P_{\text{spec}})(M_{\text{trans}}) \\
P_{\text{diff}}(\omega_o) &= 1 - P_{\text{spec}} - P_{\text{trans}}
\end{align*}
$$

where $W_{\text{lum}} = \begin{pmatrix} 0.2126 \\ 0.7152 \\ 0.0722 \end{pmatrix}$ and $M$ represents the surface material.

1. Prove $P_{\text{spec}}(\omega_o) + P_{\text{trans}}(\omega_o) + P_{\text{diff}}(\omega_o) = 1$

    Trivially,

    $$
    \begin{align*}
    &P_{\text{spec}}(\omega_o) + P_{\text{trans}}(\omega_o) + P_{\text{diff}}(\omega_o) \\
    =\enspace & P_{\text{spec}}(\omega_o) + P_{\text{trans}}(\omega_o) + 1 - P_{\text{spec}} - P_{\text{trans}} \\
    =\enspace & 1
    \end{align*}
    $$

2. Prove $P_{\text{spec}}$ is valid

    Due to the clamp between $0.05$ and $0.95$, and the linear interpolation up to $1$,
    
    $$
    0.05 \le P_{\text{spec}} \le 1.0
    $$.

3. Prove $P_{\text{trans}}$ is valid

    Since $P_{\text{spec}} \le 1.0$, then $1 - P_{\text{spec}} \ge 0.0$. Also, $M_{\text{trans}} \in [0, 1]$ and so

    $$
    0.0 \le M_{\text{trans}} \le 1.0
    $$

4. Prove $P_{\text{diff}}$ is valid

    Since $0.05 \le P_{\text{spec}} \le 1.0$, $0.0 \le M_{\text{trans}} \le 1.0$, and
    $P_{\text{spec}}(\omega_o) + P_{\text{trans}}(\omega_o) + P_{\text{diff}}(\omega_o) = 1$, then

    $$
    0.0 \le P_{\text{diff}} \le 0.95
    $$
