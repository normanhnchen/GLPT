7.5 Punctual Lights

Punctual lights are light sources that emit from a single infinitesimal point or single direction in space. There are three defined types of punctual lights: point lights, spotlights, and directional (infinite) lights.

Finite Lights

Finite lights are lights which emit from a finite point rather than an infinite direction. Finite lights include point lights and spotlights.

Because finite lights emit from a single infinitesimal point, sampling the light is deterministic and cannot be done stochastically. Therefore, the probability of a BSDF sample hitting the light is virtually 0, and so we must direct sample it with NEE.

For performance reasons, we randomly sample a finite light in the scene for NEE with rather than looping through every light in the scene. To make the rendering more efficient, we can use power sampling with an \(O(1)\) alias table method described in 7.4 Power Sampling

Light PowerFinitePunctualLightSample(float Xi, out float lightPdf) {
    int offset = min(int(Xi * numFiniteLights), numFiniteLights - 1);
    float up = min(Xi * numFiniteLights - offset, ONE_MINUS_EPSILON);

    FiniteLight flOffset = finiteLights[offset];

    int finiteLightId;
    if (up < flOffset.q) {
        finiteLightId = offset;
        lightPdf = flOffset.p;
    } else {
        finiteLightId = flOffset.alias;
        lightPdf = finiteLights[finiteLightId].p;
    }

    int lightId = finiteLights[finiteLightId].lightId;
    return lights[lightId];
}

Point Lights

A point light is a finite light that radiates light equally in all directions from a single infinitesimal position in space. We also know that its radiance falls off at \(\frac{1}{d^2}\) where \(d\) is the distance to the light (derived here).

vec3 Xi = Pcg3d(rng);

float lightPdf;
Light light = PowerFinitePunctualLightSample(Xi.x, lightPdf);

vec3 wi = normalize(light.pos - si.p);
float dist = length(light.pos - si.p);
vec3 Li = light.col * light.intensity / max(dist * dist, 0.0001);

Spotlights

A spotlight is a point light except it is restricted to a cone of directions. Similar to point lights, it has an inverse-square falloff relative to distance (derived here). We follow glTF conventions and adapt their falloff implementation:

vec3 Xi = Pcg3d(rng);

float lightPdf;
Light light = PowerFinitePunctualLightSample(Xi.x, lightPdf);

vec3 wi = normalize(light.pos - si.p);
float dist = length(light.pos - si.p);

float lightAngleScale = 1.0 / max(0.001, cos(light.innerConeAngle) - cos(light.outerConeAngle));
float lightAngleOffset = -cos(light.outerConeAngle) * lightAngleScale;

float cd = dot(normalize(-light.d), wi);
float angularAttenuation = clamp(cd * lightAngleScale + lightAngleOffset, 0.0, 1.0);
angularAttenuation *= angularAttenuation;
float attenuation = angularAttenuation / max(dist * dist, 0.0001);

vec3 Li = light.col * light.intensity * attenuation;

Infinite Lights

Directional Lights

A directional (infinite) light models an emitter so that its light travels in a parallel direction at every point in the scene. Because it has no position, there is no inverse-square falloff.

vec3 wi = normalize(-light.d);
float dist = INF;
vec3 Li = light.col * light.intensity;

Derivations

Radiance Falloff

A point light's emission can be defined as emitting some amount of power (radiant flux) \(\Phi\) measured in watts. Because a point light emission is isotropic, it emits power uniformly over a sphere which has \(4\pi\) steradians of solid angle \(\omega\). Thus, the radiant intensity (power per unit solid angle) is:

\[ I = \dfrac{\Phi}{4\pi} \]

The power carried from a small solid angle \(d\omega\) is

\[ d\Phi = I d\omega \]

By definition, a solid angle \(d\omega\) subtended by a cone projects an area \(dA = d^2 d\omega\), the radiance of the point light's emission is then defined as

\[ L = \dfrac{d\Phi}{dA} = \dfrac{Id\omega}{d^2 d\omega} = \dfrac{I}{d^2} \]

Therefore, the radiance at a distance \(d\) away from the light source falls off at \(\frac{1}{d^2}\).
